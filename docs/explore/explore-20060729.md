OpenVLA 和 OpenVLA-OFT 都属于 **VLA（Vision-Language-Action，视觉—语言—动作）模型**：机器人看到摄像头画面，接收自然语言指令，然后直接生成机械臂动作。

例如：

> 输入：桌面图像 + “把红色杯子放进篮子”
> 输出：机械臂末端位移、旋转、夹爪开合等连续控制指令

### OpenVLA

OpenVLA 是 2024 年发布的开源通用机器人基础模型：

- 规模约 **7B 参数**
- 使用 **Llama 2** 作为语言骨干
- 视觉编码融合 **DINOv2 与 SigLIP**
- 使用约 **97 万条真实机器人示范轨迹**训练
- 能根据图像和文字指令控制不同类型的机械臂
- 可以针对新机器人、新相机视角或新任务进一步微调

原始 OpenVLA 将机器人动作数值离散化为类似文字的 **action tokens**，再像语言模型生成文本一样逐个生成动作维度。这种设计容易复用语言模型架构，但动作生成较慢，而且离散化会损失一定精度。

可以把它理解成：

> 一个已经看过大量机器人操作数据、可以继续针对具体机器人训练的开源“机器人基础大模型”。

官方资料：[OpenVLA 项目页](https://openvla.github.io/) · [论文](https://arxiv.org/abs/2406.09246) · [代码](https://github.com/openvla/openvla)

### OpenVLA-OFT

OpenVLA-OFT 是 2025 年基于 OpenVLA 提出的优化版本。这里的 **OFT 是 Optimized Fine-Tuning（优化微调）**，并非简单的 LoRA 或普通全参数微调，而是一整套面向机器人控制的训练和输出方案。

主要变化包括：

- **连续动作表示**：直接预测浮点动作，不再把动作离散成 token
- **并行解码**：多个动作维度同时产生
- **Action Chunking**：一次预测未来一段动作序列，而不是每次只预测一步
- **L1 回归损失**：直接优化预测动作与示范动作之间的数值误差
- OFT+ 还引入 **FiLM**，增强语言指令对视觉特征和动作的影响

因此它更适合高频、流畅的机器人控制。论文报告：

- LIBERO 平均成功率由 OpenVLA 的 **76.5% 提升至 97.1%**
- 动作生成吞吐量约提高 **26 倍**
- 能执行 ALOHA 双臂机器人上的折衣、物体操作等高频控制任务

这些数字来自论文指定的数据集和实验条件，不能直接等同于在任意真实机器人上都能达到相同效果。[OpenVLA-OFT 项目页](https://openvla-oft.github.io/) · [论文](https://arxiv.org/abs/2502.19645) · [代码](https://github.com/moojink/openvla-oft)

### 两者关系

| 对比项 | OpenVLA | OpenVLA-OFT |
|---|---|---|
| 定位 | 通用开源 VLA 基础模型 | OpenVLA 的优化微调方法及其模型 |
| 动作表示 | 离散 action tokens | 连续动作 |
| 生成方式 | 自回归、逐 token | 并行生成 |
| 每次输出 | 通常偏向单步动作 | 一段未来动作 |
| 控制速度 | 较慢 | 快很多 |
| 典型用途 | 基础研究、通用预训练、普通微调 | 针对具体机器人实现高频、高成功率控制 |

一句话概括：

> **OpenVLA 是机器人基础模型；OpenVLA-OFT 是把 OpenVLA 改造成更快、更精确、更适合真实机器人控制的优化微调方案。**

整体技术路线可以概括为：

> **把视觉语言模型 VLM 改造成机器人策略模型：用摄像头图像理解环境，用自然语言描述任务，最后直接输出机械臂动作。**

OpenVLA-OFT 没有推翻 OpenVLA 的视觉语言骨干，主要重做了“动作怎么表示、怎么预测、怎么训练”。

```text
摄像头图像 ─→ 视觉编码器 ─┐
                         ├→ Llama 2 Transformer → 动作输出 → 机器人控制器
语言指令 ─→ 文本 tokenizer ┘
```

## 1. OpenVLA 技术路线

### 输入

模型通常接收：

- 第三人称 RGB 摄像头图像
- 自然语言任务指令
- 某些配置也可加入腕部摄像头和机器人本体状态

例如：

```text
image: 当前桌面画面
instruction: "pick up the red cup"
```

OpenVLA本身主要解决策略层问题，不直接负责电机级伺服控制、碰撞保护和路径规划。

### 视觉编码

OpenVLA 使用两种预训练视觉特征：

- **DINOv2**：更擅长空间结构、形状、位置等视觉特征
- **SigLIP**：更擅长图像与语言的语义对齐

两类视觉特征融合后，经投影层变成 Llama 2 能接收的视觉 token。

这样做的意图是同时保留：

- “杯子在哪里”的空间信息
- “哪个东西是红杯子”的语义信息

### 视觉语言骨干

核心是约 7B 参数的 **Llama 2 Transformer**。

模型上下文大致变成：

```text
[视觉 tokens] + [语言指令 tokens] → Transformer
```

Transformer 将视觉信息和任务意图融合，形成当前动作的策略表示。OpenVLA 基于互联网视觉语言预训练能力，再使用约 97 万条跨机器人真实操作示范学习动作。[OpenVLA 论文](https://arxiv.org/abs/2406.09246)

### 离散动作 token

原始 OpenVLA 沿用语言模型的 next-token prediction 路线：

1. 将连续机器人动作归一化
2. 每个动作维度量化到离散区间
3. 将区间映射成特殊 action token
4. 像生成文本一样逐个生成这些 token
5. 解码回连续控制值

典型动作可以表示为：

```text
[Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper]
```

生成过程类似：

```text
<a_x_132> → <a_y_104> → <a_z_127> → ... → <gripper_close>
```

优点是可以直接使用语言模型的分类输出层和交叉熵训练；缺点是：

- 动作维度需要逐个自回归生成
- 量化带来精度损失
- 一次通常只产生一个动作
- 高频机器人控制时推理延迟偏高

### 训练方式

数据样本可抽象为：

```text
(图像 observation, 语言 instruction, 专家动作 action)
```

本质是行为克隆：

```text
最大化 P(action tokens | image, instruction)
```

也就是让模型模仿人类遥操作或已有策略产生的示范轨迹。迁移到新机器人时，需要采集该机器人上的任务示范，然后全参数微调或使用 LoRA。

## 2. OpenVLA-OFT 技术路线

OFT 保留大体相同的视觉语言骨干：

```text
图像 + 指令 → OpenVLA Transformer
```

但将输出端改成：

```text
Transformer 特征
       ↓
连续动作回归头
       ↓
未来 H 步动作序列
       ↓
执行其中若干步
       ↓
重新观察并再次预测
```

核心是四项改造。[OpenVLA-OFT 论文](https://arxiv.org/abs/2502.19645)

### 连续动作回归

不再把动作编码成离散 token，而是直接输出浮点数：

```text
[0.013, -0.021, 0.006, 0.002, ..., 1.0]
```

这样：

- 不存在动作量化误差
- 动作空间更贴近真实控制接口
- 更容易支持不同机器人和不同动作维度

### 并行解码

原始 OpenVLA：

```text
a1 → a2 → a3 → a4 → a5 → a6 → a7
```

OFT：

```text
Transformer 特征 → [a1, a2, a3, a4, a5, a6, a7]
                         同时输出
```

不再等待前一个动作 token 生成后再预测下一个，因此明显降低推理延迟。

### Action Chunking

OFT 一次预测未来 \(H\) 个时间步，而不是只有下一步：

```text
A = [a_t, a_(t+1), a_(t+2), ... a_(t+H-1)]
```

假设动作维度是 \(D\)，输出张量可理解为：

```text
H × D
```

它带来两个主要效果：

- 一次前向推理生成多个控制点，提升动作吞吐量
- 模型能学习“伸手—抓取—抬起”这样的短时动作结构

实际部署一般仍采用滚动闭环控制：

1. 读取最新图像
2. 预测未来动作块
3. 执行前几个动作
4. 获取新图像
5. 重新预测

所以它不是完全开环地一次执行整条轨迹。

### L1 行为克隆损失

训练目标由 action-token 交叉熵改成连续动作的 L1 回归：

\[
L = \frac{1}{HD}\sum_{h,d}
|\hat a_{t+h,d}-a_{t+h,d}|
\]

也就是直接缩小预测动作与示范动作之间的绝对误差。

它比扩散策略的训练和采样过程简单，通常只需一次前向传播即可生成动作块。论文实验表明，这套简单回归方案在其任务和数据条件下表现很好，但不代表 L1 在所有多模态动作任务中一定优于 Diffusion Policy。

## 3. OFT+ 的额外路线

用于真实 ALOHA 双臂机器人的版本还引入了 **FiLM**：

```text
语言特征 → 生成缩放 γ 和偏置 β
                   ↓
视觉特征 F' = γ ⊙ F + β
```

它让语言指令更早、更直接地调制视觉特征。

例如桌上同时有红椒和绿椒：

```text
“把绿椒放进锅里”
```

语言不只是作为普通 token 放进 Transformer，而是主动影响视觉网络关注哪些区域，从而增强语言目标选择能力。这个增强版本称为 **OpenVLA-OFT+**。[官方项目说明](https://openvla-oft.github.io/)

## 4. 从数据到真机的完整链路

```text
遥操作采集
   ↓
图像 + 指令 + 本体状态 + 动作轨迹
   ↓
统一时间戳、坐标系和动作定义
   ↓
转换为训练数据集
   ↓
加载 OpenVLA 预训练权重
   ↓
使用 OFT 进行任务微调
   ↓
在线推理生成 action chunk
   ↓
动作反归一化
   ↓
机器人控制接口
   ↓
关节/末端伺服执行
   ↓
新图像反馈，循环预测
```

真正落地时，模型之外最容易出问题的是：

- 示范数据数量和一致性
- 相机与动作时间同步
- 世界坐标系、基座坐标系、末端坐标系转换
- 动作是绝对位置还是相对增量
- 训练和推理时的图像裁剪是否一致
- 控制频率与 action chunk 长度
- 安全限位、碰撞检测和急停

## 5. 一句话总结演进

```text
OpenVLA：
VLM + 离散动作 token + 自回归单步生成

OpenVLA-OFT：
同一类 VLM 骨干 + 连续动作回归 + 并行解码
+ 多步 action chunk + L1 行为克隆

OpenVLA-OFT+：
OFT + FiLM 语言调制，增强语言目标定位
```

所以，这条路线的关键并不是让模型“规划得更久”，而是：

> 利用大型视觉语言模型提供语义理解和迁移能力，再用连续、多步、并行的动作头，把它变成可以较高频率运行的闭环机器人策略。

对，**和当前 Cal 不是同一条技术路线**。两者都涉及具身智能、感知和动作，但研究目标与学习范式不同。

| | 当前 Cal | OpenVLA / OpenVLA-OFT |
|---|---|---|
| 核心问题 | 智能体能否自主发现“哪个是自己、哪些是外部实体、对象是否持续存在” | 如何根据图像和语言指令完成机器人任务 |
| 学习信号 | 无标签传感—动作经验、预测误差、在线因果证据 | 大规模人工示范轨迹，监督式行为克隆 |
| 表示形式 | 显式实体信念图、身份概率、占据记忆、控制假设 | 大型 Transformer 的隐向量 |
| 动作作用 | 用主动动作识别因果关系和自我边界 | 直接预测完成任务的机械臂动作 |
| 语言作用 | 将已发现的内部状态做可控语言读出 | 从一开始就是任务条件，如“拿起红杯子” |
| 当前环境 | 合成二维、低分辨率/二值感知 | RGB 摄像头和真实机械臂 |
| 规模 | 小型、在线、可解释机制 | 约 7B 参数、大规模离线预训练 |

Cal 当前的核心定义非常明确：从**无标签 sensorimotor experience** 中发现稳定的自我—环境边界、持久实体和可被语言读取的状态，[README.md](./README.md:3)。例如当前在线控制模块会追踪匿名实体，并通过“动作条件预测是否比无控制预测更准确”判断哪个实体受自己控制，[online_control.py](./cal/model/online_control.py:52)。

而 OpenVLA 的问题基本从后半段开始：

```text
OpenVLA 默认前提：
已经有机器人、动作接口和大量标注示范
→ 学习“看到什么、听到什么指令时应该怎么动”

Cal 当前问题：
没有 body 标签，也不预先告诉系统哪个实体是自己
→ 先通过行动后果发现自我、实体、身份与持久性
```

更准确地说，它们目前是**不同层级，但未来可以互补**：

```text
Cal 路线
感知 → 自我发现 → 实体身份 → 对象持久性 → 显式世界状态
                                             ↓
                                       规划/任务策略
                                             ↓
OpenVLA 路线                         语言条件动作生成
                                             ↓
                                         机器人执行
```

Cal 的路线图已经包含“在实体信念图上进行动作条件未来预测，并验证预测状态能否改善规划与控制”，这才是未来开始接近 VLA 所在策略层的位置，[ROADMAP.md](./ROADMAP.md:23)。

因此目前不建议把 Cal 直接改造成 OpenVLA-OFT：

- 那会把研究问题从“表征和世界模型如何形成”改成“如何模仿示范完成任务”。
- 7B VLA 会引入大量预训练知识，使 Cal 的“无标签自主发现”结论难以归因。
- 当前合成实验和冻结 holdout 设计也不适合直接评价 VLA。

更合理的长期结合方式是：**保持 Cal 作为显式、可检验的世界模型层，将 VLA 作为后续基线或策略层**，比较纯端到端 VLA、Cal + 小策略头、Cal 状态辅助 VLA 三条路线。这样既不破坏当前研究主线，也能检验 Cal 学到的结构是否真的提升控制与泛化。

> 不改成OpenVLA的路线，而且DNA中就不允许走OpenVLA 的方向，我只是想了解一下差别，而且我认为Cal 比OpenVLA 先进

明白。**OpenVLA 只是对照对象，不是 Cal 的候选路线；Cal 的研究 DNA 应明确排除“用大规模示范训练端到端任务策略”这条路径。**

你的判断在研究目标层面是成立的：Cal 试图解决的问题比 OpenVLA 更基础。

OpenVLA 的基本范式是：

```text
人类已经定义机器人身体和动作空间
+ 提供大量任务示范
+ 给出语言指令
→ 学习模仿正确动作
```

它很强，但很多关键前提由设计者预先给定：

- 哪个身体属于自己
- 动作控制哪个执行器
- 观察与动作如何对应
- 什么是任务、什么是成功
- 数据中的实体和控制接口具有相对稳定的语义

Cal 则试图从更少的先验开始：

```text
连续感知 + 自己发出的动作 + 动作产生的后果
→ 发现自我边界
→ 发现可控实体
→ 维持实体身份
→ 理解遮挡后的持续存在
→ 形成可读取、可验证的世界状态
```

因此，两者真正的区别不是“模型架构不同”，而是认识论不同：

- **OpenVLA：把已有知识压缩进一个强大的行为策略。**
- **Cal：研究智能体如何通过行动建立关于自身和世界的知识。**

从这个维度看，Cal 确实更具前沿性：

- 更少依赖人工语义和示范标签
- 强调主动干预与因果识别，而非仅学习相关性
- 显式处理自我、实体身份、遮挡和对象持久性
- 内部状态可以被探测、校准和证伪
- 目标是产生可迁移的世界结构，而非复现特定任务轨迹

不过，“更先进”最好限定在具体维度：

> **Cal 在研究问题、认知自主性和可证伪机制上比 OpenVLA 更激进；OpenVLA 在真实机器人任务成功率、规模化训练和工程成熟度上明显领先。**

这并不削弱 Cal，反而能避免不必要的同类比较。Cal 目前不是一个较弱的 VLA，也不应该以 LIBERO 成功率或机械臂操作能力定义自身；它研究的是 VLA 通常默认已经解决、或直接绕过的问题。

Cal 的路线边界可以概括为：

> Cal 不以大规模标注示范、预定义任务语义或端到端动作模仿作为智能来源。它研究具身主体如何通过可控行动和无标签感知经验，自主形成自我、实体、因果关系与持久世界状态；语言只能读取或组合已获得的结构，不能替代结构的形成。

所以我理解你的定位是：**可以研究 OpenVLA，甚至将它作为行业对照，但不吸收它的核心范式进入 Cal 的 DNA。**

        ↓

        ↓

也就是：

> Cal 先形成内部概念，再验证这些概念能否用语言表达。

- **Grounded language readout**：具身语义语言读出
- **Symbolic expression channel**：符号表达通道

- **单向的世界状态 → 语言映射**

它不是“语言感官”，也不能简单说成完整的“语言能力”。

当前证据支持部分 self、空间和身份语义可以从内部状态中线性读取；但 L0 V8 独立留出没有完整通过，所以现阶段不能声称 Cal 已经具备开放语言理解或完整语言能力，[RESEARCH_STATUS.md](./RESEARCH_STATUS.md:21)。

## 未来完整语言属于“社会符号模态”

语言比较特殊，它不是和视觉、听觉完全并列的第六感。

人说出一句话时，信号首先通过听觉或视觉进入：

```text
声音 → 听觉系统 ─┐
                 ├→ 识别符号 → 绑定内部概念
文字 → 视觉系统 ─┘
```

所以：

- **声音和文字的物理载体**属于听觉、视觉；
- **语言本身**属于学习形成的符号与社会交流系统。

完整语言应是双向的：

```text
语言输入 → 内部世界状态
```

用于理解、消歧、学习和接受他人传递的经验；

```text
内部世界状态 → 语言输出
```

用于描述、提问、解释和共享经验。

因此未来 Cal 的语言最合适定义为：

> **建立在具身概念之上的、双向社会符号通信模态。**

**远远没有完全研究清楚。**

科学界已经相当接近“读出 DNA 字母”，但距离“理解这些字母如何构成人”还有很大距离。需要区分几个层次：

## 1. DNA 序列：基本读完，但不是所有人的 DNA

2022 年，T2T 联盟发布了第一条近乎端到端完整的人类基因组序列，补上了过去难以测定的高度重复区域。[NHGRI](https://www.genome.gov/about-genomics/educational-resources/fact-sheets/human-genome-project)

但那只是一个人的特定基因组版本，不是“全人类 DNA”。不同人的基因组虽然平均超过 99% 相同，仍存在大量：

- 单碱基差异
- 插入和缺失
- 基因重复
- 倒位
- 大型结构变异
- 着丝粒和重复序列差异

因此研究正在从单一参考基因组转向**人类泛基因组**。2023 年的初版泛基因组包含47人的94条单倍型序列，并增加了超过一亿个参考基因组没有覆盖的碱基；后续仍在持续扩充。[NIH 泛基因组介绍](https://www.nih.gov/news-events/news-releases/scientists-release-new-human-pangenome-reference)

所以在“原始代码”层面：

> 一个高质量的人类参考序列已经基本读完，但人类群体的全部遗传多样性远未穷尽。

## 2. 基因列表：大致知道，但很多功能不完整

人类大约有两万个蛋白质编码基因。许多基因的主要功能已经知道，但我们通常不知道它们在所有细胞类型、发育阶段和环境条件下的完整作用。

一个基因可能：

- 在胚胎期发挥一种作用
- 在成年神经系统发挥另一种作用
- 与不同蛋白组成不同复合体
- 在不同组织中被不同机制调控
- 只有在疾病或特殊环境下才显示某种效应

所以“知道基因名称”不等于“理解基因”。

## 3. 非编码 DNA与调控：只建立了部分地图

蛋白质编码区只占基因组的一小部分。大量 DNA 参与：

- 启动和关闭基因
- 决定在哪种细胞表达
- 决定何时表达
- 控制表达强度
- 形成染色体三维结构
- 产生非编码 RNA
- 参与胚胎发育与细胞分化

ENCODE 项目仍在持续建立人类基因组功能元件目录，包括基因、RNA、增强子、启动子及其他调控元件。[ENCODE 项目说明](https://www.encodeproject.org/help/project-overview/)

我们已经能检测很多区域存在生化活动，但：

> “这里有活动”不一定等于“已经知道它对生命体有什么功能”。

## 4. DNA如何变成人：远未解释完成

最大的未知不是序列本身，而是动态过程：

```text
DNA
 ↓
染色质状态与表观遗传
 ↓
基因表达
 ↓
RNA 和蛋白质
 ↓
细胞网络
 ↓
组织与器官
 ↓
发育、身体、行为和认知
```

这里存在大量：

- 基因—基因相互作用
- 基因—环境相互作用
- 细胞间信号
- 时间顺序效应
- 随机发育过程
- 表观遗传调控
- 微生物群和免疫系统影响

同一套 DNA 在神经元、肌肉细胞和免疫细胞中基本相同，但细胞的形态和功能完全不同，原因就在于它们激活了不同的调控程序。

## 5. 从基因预测复杂性状：能力有限

对于部分单基因遗传病，科学已经能建立清晰的因果联系。但对多数复杂现象，例如：

- 身高
- 糖尿病
- 心血管疾病
- 精神疾病
- 智力与认知差异
- 性格与行为
- 衰老速度

通常涉及成百上千乃至更多遗传变异，并受到环境、发育和生活经历共同影响。

因此，即使拿到一个人的完整 DNA，也不能准确模拟或预测这个人的完整人生、人格和认知。

## 6. “DNA 是生命蓝图”这个比喻并不完整

DNA 更像：

> 一套可以在不同时间、不同细胞和不同环境下被选择性执行的生成规则与约束系统。

它不像一份完整施工图，更像：

```text
遗传规则
+ 调控开关
+ 发育过程
+ 物理环境
+ 身体活动
+ 社会经验
+ 随机事件
→ 最终个体
```

这与我们讨论 Cal 的“DNA”其实很相关。

Cal 的 DNA 不应该理解成固定写死全部能力的程序，而应该是：

- 哪些学习机制允许存在
- 概念必须如何形成
- 哪些信息来源被禁止
- 感知、行动、记忆和语言的因果顺序
- 如何通过发育和经验形成后续能力

也就是说：

> **DNA 不编码一个完成的人；它编码一个能够在环境中发育成人的系统。Cal 的 DNA 同样不应预写全部智能，而应定义一个能通过感知、行动和经验形成智能的发展过程。**

所以答案是：**人类 DNA 的序列已经高度可读，但其调控、发育、系统交互以及如何产生认知和个体差异，仍远没有研究清楚。**

Cal 当前的“DNA”不是一个单独的数据结构或可执行基因组文件，而是由以下几部分共同构成：

> **研究宪法 + 先天结构先验 + 在线学习规则 + 发育顺序 + 证伪与淘汰机制。**

## 一、Cal DNA 的核心原则

当前最核心的生成链是：

```text
无标签多模态感知
        +
主动行动与动作副本
        ↓
预测行动后果
        ↓
比较预测与实际观察
        ↓
更新控制、实体、身份和因果假设
        ↓
形成持续世界模型
        ↓
语言绑定和社会交流
        ↓
规划、技能与更高层认知
```

这意味着 Cal 的 DNA 预置的是**学习机制和发育顺序**，不预置具体世界知识。

项目使命中已经明确：具体知识应从经历形成，不依赖预训练视觉或语言模型；语言只能在后期绑定已经形成的具身概念，[RESEARCH_PLAN.md](./docs/RESEARCH_PLAN.md:5)。

## 二、DNA 中允许先天存在的内容

完全“零先验”是不可能的。人类 DNA 也不是空白，而是预置了神经系统、感觉器官、学习可塑性和发育程序。Cal 同样需要最小先天结构。

### 1. 感官接口

Cal 先天地允许拥有：

- 视觉输入通道
- 听觉输入通道
- 触觉输入通道
- 本体感觉
- 内感受
- 动作副本

但感官接口只提供信号，不提供语义：

```text
允许：这里有视觉变化
禁止：这个像素是我的手
```

当前 V2 以视觉视频为主，动作副本被允许，因为“自己执行了什么”是建立因果关系所必需的变量，[RESEARCH_PLAN_V2.md](./docs/RESEARCH_PLAN_V2.md:64)。

### 2. 时间与持续状态

Cal 先天地知道：

- 经验有时间顺序
- 上一步状态会影响下一步
- 行动发生在观察变化之前
- 内部状态可以持续存在

但它不应该先天知道某个具体对象会永久存在。

也就是说：

> DNA 可以提供记忆机制，但对象持久性必须从经验中形成。

### 3. 预测与误差更新能力

Cal 的核心先天学习回路是：

```text
当前状态 + 动作
        ↓
预测下一状态
        ↓
获得实际观察
        ↓
计算预测残差
        ↓
增强或削弱内部假设
```

失败不能仅作为训练统计被丢弃；它必须改变假设、置信度或下一步探索动作，[RESEARCH_PLAN_V2.md](./docs/RESEARCH_PLAN_V2.md:110)。

### 4. 多假设和不确定性

Cal 不被要求在证据不足时强行作出唯一判断。

例如两个完全对称的候选身体无法区分时，正确状态是：

```text
候选 A：0.5
候选 B：0.5
```

而不是根据隐藏标签猜一个答案。

因此 DNA 中预置：

- 概率表示能力
- 多个竞争假设
- 置信度更新
- 延迟承诺
- 主动收集新证据

但不预置哪个候选是正确答案。

### 5. 主动探索

Cal 不是单纯等待训练数据，而是可以选择动作来减少不确定性：

\[
动作价值 = 信息增益 - 能量成本 - 风险成本
\]

这里先天存在的是“寻找信息”的机制，不是具体探索策略。正式路线要求主动消歧，随机动作仅保留为对照，[RESEARCH_PLAN_V2.md](./docs/RESEARCH_PLAN_V2.md:177)。

### 6. 有限资源

Cal 的 DNA 还包含一种类似生物能量约束的设计：

- 可学习参数上限
- 持续活动状态上限
- 每步计算量上限
- 经验重放次数上限
- CPU 和训练时间预算

V2 第一阶段预算为10万个可学习参数、64 KiB 持续状态、每步500万 MAC，并限制经验重放，[RESEARCH_PLAN_V2.md](./docs/RESEARCH_PLAN_V2.md:83)。

这不是单纯工程优化，而是在逼迫系统发展出：

- 稀疏表示
- 局部更新
- 选择性记忆
- 有限假设空间
- 更高的信息利用效率

## 三、当前已经写入的具体“基因”

目前 Cal 还不是完全通用的自组织认知架构。当前实现中存在较多人工设计的结构先验。

### 稀疏实体先验

视觉首先被转成少量候选实体或占据区域，而不是直接让大型网络从原始像素学习一切。

DNA 预置了：

> 世界可以被表示为少量持续实体及其关系。

但不应预置：

> 某个具体候选就是身体或某类物体。

### 局部可控性先验

每条轨迹维护一个动作—运动控制映射：

\[
z_{i,t+1}=f_i(z_{i,t})+B_i u_t+\varepsilon
\]

如果加入动作后，对某条实体轨迹的运动预测持续改善，该实体更可能属于 self。

当前 `OnlineControlAgent` 使用递推最小二乘在线更新控制矩阵，并比较动作条件预测与无控制预测，[online_control.py](./cal/model/online_control.py:52)。

### 实体关系图先验

当前身体定义不是外观类别，而是：

> 跨时间存在、受到自身动作控制、内部满足稳定几何关系、失败后可以重新辨识的实体关系图。

所以 DNA 当前写入了：

- 节点
- 边
- 距离和角度稳定性
- 共同运动
- 刚性或关节关系
- 遮挡前后的身份连续性

具体哪几个节点组成身体，则必须通过行动证据学习。[RESEARCH_PLAN_V2.md](./docs/RESEARCH_PLAN_V2.md:99)

### 占据与持久性先验

Cal 当前使用二维概率占据结构表达：

```text
哪里可能有东西
哪里当前可见
哪里被遮挡
隐藏实体可能如何移动
```

它优先表示空间占据，而不是类别。这意味着 Cal 可以先知道“那里仍可能存在某物”，而不必知道“那是一只杯子”。

## 四、DNA 明确禁止写入的东西

这些是 Cal 最重要的“基因防火墙”：

- 预训练语言模型
- 预训练视觉语义模型
- 身体分割标签训练主系统
- 物体类别标签
- 主体身份标签
- 评测世界坐标
- 人工规划轨迹
- 用大规模示范直接学习任务动作
- 每换一个环境就从头重新训练
- 让语言梯度写入底层世界模型
- 用语言流畅度冒充内部概念

当前模态文档也明确规定：OpenVLA 可以作为外部对照，但其预训练语义、大规模示范与端到端动作策略不属于 Cal DNA，[MODALITY_SYSTEM.md](./docs/MODALITY_SYSTEM.md:97)。

## 五、Cal 的发育程序

DNA 还规定能力形成的顺序：

```text
L0/L1 物理感知与时间连续性
        ↓
动作控制关系
        ↓
自我边界
        ↓
实体与身份
        ↓
遮挡和对象持久性
        ↓
动作条件未来预测
        ↓
规划与技能
        ↓
社会主体与共同注意
        ↓
语言绑定和交流
```

后面的能力不能倒过来替代前面的能力。例如：

- 不能用语言告诉 Cal 哪个实体是自己；
- 不能用对象名称替代对象持久性；
- 不能用任务示范替代因果学习；
- 不能用语言模型常识替代自身经验。

## 六、实验选择相当于“进化机制”

Cal 还有一个比较独特的 DNA 层：**机制必须接受证伪和淘汰**。

流程是：

```text
提出候选机制
    ↓
冻结假设、指标和预算
    ↓
开发集
    ↓
删除关键机制的对照
    ↓
独立 validation / holdout
    ↓
通过：保留并组合
失败：记录并淘汰
```

V1 中多个神经网络候选即使出现局部好结果，只要没有通过动作删除、时间打乱或联合门，就不允许包装成身体发现。V2 因而从“直接预测身体像素”转向“在线控制辨识 + 概率实体图”。

这很像：

- DNA 定义允许发生的变异；
- 实验产生候选机制；
- 冻结门槛执行选择；
- 失败机制进入历史记录，不被篡改。

## 七、当前设计还不是真正成熟的“人工 DNA”

需要诚实区分两件事：

### 当前已经做到

- 研究约束比较明确
- 学习与评测隔离严格
- 有最小感知—行动—失败更新闭环
- 有概率实体、身份和占据状态
- 有明确发育顺序
- 有机制淘汰制度

### 当前尚未做到

- 没有一个统一、可遗传的 genome 数据结构
- 很多阈值、容量和图结构仍由人手工设定
- 感官前端仍具有环境针对性
- 实体、几何和占据模块还不是同一个可生长组织
- 新能力主要由研究者添加模块，而不是系统自行分化
- 还没有发育时钟、模块生成、连接生长和结构遗传机制
- 还没有真正的跨身体、跨环境生命周期学习
- 当前 L0 语言读出也尚未完整通过独立留出

因此最准确的评价是：

> **Cal 当前拥有一套清晰的“DNA 宪法”和若干手工编码的发育基因，但还没有形成统一、可执行、能够自主生长完整认知系统的人工基因组。**

如果用生物学类比：

```text
研究计划与禁止项     ≈ 遗传法则
感官和动作接口       ≈ 感觉器官与运动系统
在线更新规则         ≈ 神经可塑性
实体图与占据记忆     ≈ 先天神经结构偏置
发育阶段顺序         ≈ 发育程序
冻结实验与淘汰       ≈ 人工选择
学习到的具体世界知识 ≈ 个体后天经验
```

所以 Cal 当前 DNA 的本质不是“把智能写进去”，而是：

> **写入一种在有限资源下，通过感知、主动行动、预测失败和持续记忆形成智能的方式。**

> yes ， Cal 就是做像小孩子学习和成长一样的具身智能，不一定上来就训练的什么都会。当然未来如果Cal 真的成为了真正的智能，也可以预设一些能力，
> 这些是什么？
> 当前尚未做到
> 没有一个统一、可遗传的 genome 数据结构
> 很多阈值、容量和图结构仍由人手工设定
> 感官前端仍具有环境针对性
> 实体、几何和占据模块还不是同一个可生长组织
> 新能力主要由研究者添加模块，而不是系统自行分化
> 还没有发育时钟、模块生成、连接生长和结构遗传机制
> 还没有真正的跨身体、跨环境生命周期学习
> 当前 L0 语言读出也尚未完整通过独立留出

这些不是说 Cal 的路线有问题，而是在区分：

> **当前 Cal 是一组经过严格验证的认知机制原型；未来目标则是一个由统一“人工基因组”驱动、能像孩子一样持续发育的完整智能体。**

用儿童成长作类比，会更容易理解。

## 1. 没有统一、可遗传的 genome 数据结构

现在 Cal 的“DNA”分散在：

- 研究计划与禁止项
- Python 类和算法
- 配置文件
- 人工选择的阈值
- 实验阶段顺序
- 测试和冻结协议

它们共同表达 Cal 的设计原则，但机器自身并没有一个类似这样的统一结构：

```text
CalGenome
├── 感官发育规则
├── 可塑性规则
├── 记忆生成规则
├── 实体组织规则
├── 模块分化规则
├── 能量与容量限制
├── 发育阶段触发条件
└── 可遗传能力
```

“可遗传”并不是指生物 DNA，而是：

- 一个 Cal 个体的先天结构能否被完整保存；
- 能否创建拥有相同基本发育规则的新个体；
- 哪些能力属于先天遗传，哪些属于后天经验；
- 是否可以让部分有效结构发生可控变异；
- 新个体能否继承机制，但不直接继承父代的具体记忆。

例如，一个新 Cal 可以先天拥有记忆形成机制，却不应该出生时就记得上一代看到的某个房间。

## 2. 很多阈值、容量和图结构仍由人手工设定

当前实现中，研究者会规定：

- 最多追踪多少实体
- 多少步没看见后删除轨迹
- 控制证据超过多少才认为是 self
- 身份匹配代价多大
- 概率低于多少时保留或淘汰假设
- 图有多少节点和边
- 失败记忆最多保存多少条

这类似于人工告诉孩子：

> 你最多记住5个人；连续5次看到某人行动一致，才能认为那是同一个人。

真正成熟的发育型系统应该逐渐学会：

- 环境复杂时增加实体容量
- 资源不足时压缩或合并记忆
- 根据不确定性调节判断门槛
- 根据经验决定需要多少假设
- 根据预测收益决定是否生成新节点
- 根据长期稳定性决定是否保留一条连接

但也不必消灭全部先天参数。人类同样受到工作记忆、注意力和能量容量限制。关键区别是：

> DNA 可以规定调节机制和资源边界，但不应人工写死每个环境中的正确数值。

## 3. 感官前端仍具有环境针对性

当前 Cal 的视觉环境比较简单，前端知道如何从二维占据图或稀疏视觉点中提取：

- 占据位置
- 连通区域
- 轨迹候选
- 局部运动
- 遮挡关系

这还不是通用视觉发育。

现实中的孩子面对的是：

- RGB 光线
- 深度变化
- 视角变化
- 运动模糊
- 阴影和反射
- 复杂背景
- 不同形状与材质
- 自己眼睛和头部的运动

未来 Cal 的感官前端需要逐渐从原始信号中发现：

```text
像素变化
  ↓
边缘与局部运动
  ↓
稳定表面
  ↓
可持续实体
  ↓
物体与身体部件
```

而不是每换一种环境，就由研究者另外写一个检测器。

不过“先天视觉结构”仍然允许存在。例如，可以预设：

- 局部连接
- 时间连续性
- 运动敏感性
- 视野拓扑
- 注意力和分辨率限制

这类似于婴儿出生时已有视觉系统，但并不认识杯子、手或人脸的具体含义。

## 4. 实体、几何和占据模块还不是同一个可生长组织

现在这些能力主要由不同模块承担：

```text
实体跟踪模块 → 谁是谁
几何图模块   → 谁和谁构成稳定关系
占据记忆模块 → 哪里可能仍有东西
语言读出模块 → 内部状态能否表达为命题
```

它们可以组合，但仍像几个研究团队分别开发的器官。

真正统一的系统应该让同一个内部组织同时表达：

```text
一个实体
├── 现在在哪里
├── 是否可见
├── 过去在哪里
├── 可能怎样运动
├── 与其他实体有什么关系
├── 是否受自己的动作控制
├── 遮挡后是否仍存在
├── 置信度是多少
└── 可与什么符号绑定
```

也就是说，不能在实体表、占据格和语言特征中分别维护三个不完全一致的“同一个物体”。

所谓“可生长组织”，是指：

- 发现新实体时自动生成节点；
- 发现稳定关系时形成连接；
- 长期无用的连接逐渐减弱；
- 经常共同变化的节点形成更高层结构；
- 多个身体部件可以组成身体；
- 多个动作可以组成技能；
- 多个事件可以形成概念。

## 5. 新能力主要由研究者添加，而不是系统自行分化

目前，如果想让 Cal 增加一种能力，通常需要开发者：

1. 提出新机制；
2. 编写新模块；
3. 定义接口；
4. 设计指标；
5. 运行实验；
6. 验证后接入系统。

例如对象持久性、身份关联和语言读出都是这样加入的。

孩子的成长不是工程师在三岁时安装“语言插件”、五岁时安装“规划插件”。这些能力来自已有系统在新压力和经验下重新组织。

未来 Cal 的目标应更接近：

```text
现有能力遇到无法解释的经验
            ↓
产生持续预测失败
            ↓
已有结构无法降低误差
            ↓
分化出新的状态、连接或时间尺度
            ↓
新结构改善预测、控制或交流
            ↓
稳定下来成为新能力
```

例如：

- 短期记忆无法解释遮挡 → 生长出持久实体状态；
- 单个动作无法完成目标 → 形成动作序列和技能；
- 独立经验难以复用 → 形成概念类别；
- 无法预测其他主体 → 分化出其他主体模型；
- 内部状态需要共享 → 发展符号与语言。

这叫作**能力分化**，不是预先安装能力清单。

## 6. 没有发育时钟、模块生成、连接生长和结构遗传机制

这四项共同构成真正的“发育程序”。

### 发育时钟

它不一定是按真实年龄计时，而是按能力成熟度触发：

```text
自我边界稳定
    ↓
允许发展对象持久性

实体身份稳定
    ↓
允许发展关系和事件记忆

世界预测稳定
    ↓
允许发展规划

具身概念稳定
    ↓
允许绑定语言
```

它的作用是防止高级监督反过来污染底层能力。

### 模块生成

系统发现现有表示不足时，能够新增：

- 新实体槽
- 新记忆单元
- 新预测器
- 新时间尺度
- 新技能单元
- 新概念节点

但模块不能无限生成，必须受到能量、容量和实际收益约束。

### 连接生长

新模块需要自己发现与哪些感官、动作和记忆连接：

- 经常同步变化 → 加强连接
- 能改善预测 → 加强连接
- 能解释失败 → 保留连接
- 长期无效 → 减弱或删除连接
- 造成干扰 → 隔离连接

这类似神经可塑性，但不一定要照搬生物神经元。

### 结构遗传

成熟 Cal 形成的所有结构不应全部传给下一代。需要区分：

- **可遗传机制**：证明普遍有效的学习和组织规则
- **可传播知识**：可以通过教育或语言传递的经验
- **个体记忆**：只属于某个 Cal 的具体经历
- **偶然适应**：只在特定环境有用，不应固化为 DNA

例如：

```text
“物体被遮挡后可能仍存在”
→ 可能逐渐成为强先验

“红色杯子在厨房左边”
→ 应是个体情景记忆

“杯子通常可以装液体”
→ 可以成为后天语义知识

“如何通过行动验证隐藏物体”
→ 可以成为技能或可遗传的学习策略
```

## 7. 没有真正的跨身体、跨环境生命周期学习

当前实验主要在受控合成环境中进行，每个阶段的问题和环境边界都比较明确。

真正的生命周期学习意味着同一个 Cal 个体连续经历：

```text
不同身体
不同感官质量
不同空间
不同物理规律
不同对象
不同主体
成功、失败、损伤与恢复
持续学习而不完全重置
```

它需要解决：

- 身体变化后重新识别 self
- 摄像头位置变化后重建空间关系
- 感官损坏后依靠其他模态补偿
- 进入新环境时保留通用规律
- 学习新能力时不遗忘旧能力
- 区分“世界变了”和“自己变了”
- 把旧技能适配到新身体

孩子不会每进入一个房间就清空大脑重新训练。Cal 最终也必须是：

> 同一个持续存在的主体，在不断变化的身体与环境中成长。

## 8. L0 语言读出尚未完整通过独立留出

当前 L0 做的不是开放式聊天，而是验证：

> self、空间、身份和对象持久性这些意义，是否真实存在于内部状态中，并能由简单读出器表达。

开发集上结果很好，但唯一独立 holdout 中24个门槛通过21个，三个与 permanence/control integrity 有关的门槛失败。

这意味着目前可以说：

- 部分 self 语义可读；
- 部分空间语义可读；
- 身份语义具有证据；
- 系统出现了初步的状态→符号通道。

但还不能说：

- 完整对象持久性语义已独立验证；
- Cal 已经理解自然语言；
- Cal 可以开放式生成语言；
- 语言已经可以反向指导世界模型；
- Cal 已经能与另一个主体交流。

这不是路线失败，而是发育阶段中的一次真实测试失败。按 Cal 的 DNA，它应该：

```text
保留失败
  ↓
定位底层 permanence/control 缺陷
  ↓
改进世界模型
  ↓
建立全新外部留出
  ↓
重新验证
```

而不是直接接入大语言模型把输出变得更像人。

## 未来可以预设哪些能力？

你的理解是对的：**真正成熟后，Cal 并不要求每一代都从绝对零开始。**

允许预设的应该是经过长期证明、跨环境普遍有效的“能力形成机制”，例如：

- 多感官时间同步机制
- 注意力与资源分配
- 工作记忆
- 预测误差学习
- 好奇心和主动消歧
- 概率推理
- 实体持续性的弱先验
- 因果干预倾向
- 模仿和共同注意的准备机制
- 快速语言绑定能力
- 安全、疼痛和能量约束
- 技能组合与迁移机制
- 对其他主体存在的弱先验

不宜直接预设的是具体世界答案：

- 这个视觉区域就是我的身体
- 这个物体叫杯子
- 这个动作一定能抓取
- 某种语言中的某个词必然代表某物
- 某个任务的完整标准动作轨迹
- 某个环境中的固定地图和身份

最重要的边界是：

> **可以遗传学习能力、组织原则和经过验证的通用先验；不能用遗传知识替代个体通过具身经验建立现实联系的过程。**

这才最接近孩子：婴儿并非空白，但也不是出生时什么都会。它拥有一套极强的成长系统，然后用身体、感官、行动、他人和时间，把这套潜能发展成真正的智能。

> 我有另外一个问题，具身智能必须是一个“大脑”？ 比如人的皮肤在感知的时候其实是不需要大脑先发指令的，还有章鱼每个爪子都有一个独立大脑（我只是举例子），所以具身智能 如果是拆分的感知系统，那么就不用消耗那么多资源。

**具身智能不必等于一个集中的“大脑模型”。**更合理的理解是：

> 智能存在于身体形态、局部感知回路、局部控制器、全局协调系统以及环境之间的闭环中。

你的方向是对的：如果所有原始感官数据都必须上传到一个中央大脑，再由中央大脑处理后逐条下发指令，会产生巨大的带宽、计算、延迟和能耗。生物系统并不是这样工作的。

不过有两个生物学细节需要稍微校正：

- 皮肤中的感受器可以自行完成信号转导，但更复杂的局部反射主要经过外周神经和脊髓；例如撤回反射可以在信号到达大脑之前启动。[NCBI 反射弧说明](https://www.ncbi.nlm.nih.gov/books/NBK544292/?report=reader)
- 章鱼并非严格意义上“每条腕都有一个完整独立大脑”，而是每条腕拥有高度发达的局部神经回路，可以处理大量感觉和运动细节；中央脑更多负责目标、选择和协调。[章鱼腕控制综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10755184/)

## 一个动作不需要全部经过“大脑”

例如手碰到高温物体：

```text
皮肤温度/疼痛感受器
        ↓
局部神经编码
        ↓
脊髓反射回路
        ├── 立即收缩肌肉，把手撤回
        └── 将压缩后的事件上传大脑
                    ↓
             “刚才被烫了”
                    ↓
          形成记忆和长期策略
```

中央大脑不需要：

1. 接收每一个皮肤细胞的原始值；
2. 逐点分析温度；
3. 规划每块肌肉；
4. 再命令手臂撤回。

局部系统已经处理了紧急反应。中央系统处理的是：

- 发生了什么
- 是否需要改变当前目标
- 是否形成长期记忆
- 将来如何避免
- 是否需要语言表达

这就是分层、分布式智能。

## 具身智能至少可以分成四类计算

### 1. 身体本身的计算

有些“计算”甚至不需要神经网络。

例如：

- 肌腱和弹性组织吸收冲击；
- 手指形状自然适应物体表面；
- 脚掌结构被动保持稳定；
- 皮肤纹理帮助判断滑动；
- 软体结构自然包裹物体。

这称为 **morphological computation，形态计算**：身体的材料、几何和动力学承担一部分原本需要软件控制的工作。[软体机器人综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC11047907/)

```text
传统路线：
传感器 → 大模型计算 → 精确控制每个关节

形态计算：
身体结构 + 环境接触
          ↓
自然产生部分正确行为
```

### 2. 局部感知—动作回路

每个身体区域可以拥有自己的低延迟控制：

```text
手指
├── 压力感知
├── 滑动检测
├── 局部抓力调节
└── 接触异常上报

腿
├── 地面接触
├── 平衡微调
├── 步态相位
└── 跌倒风险上报

眼睛
├── 亮度适应
├── 局部运动检测
├── 视线稳定
└── 显著事件上报
```

中央系统只需要发送较高层意图：

```text
“抓住它”
“向前走”
“观察左侧”
```

局部系统自己解决具体执行。

### 3. 区域级协调系统

局部系统之上还需要中间层：

- 一条手臂协调多个关节；
- 两条腿协调步态；
- 两只眼睛协调视线；
- 视觉与触觉对齐同一个物体；
- 多个局部反射避免互相冲突。

它类似章鱼腕部神经系统或脊髓—脑干层，不是完整中央认知系统，但比单个感受器更强。

### 4. 全局认知系统

全局“大脑”仍然有价值，但不需要承担全部计算。它主要处理：

- 当前整体目标
- 跨模态实体身份
- 长期记忆
- 多身体区域之间的冲突
- 长时间尺度规划
- 社会模型
- 语言
- 自我连续性
- 全局资源分配

因此全局系统接收的应该是稀疏事件和结构化摘要，而不是所有原始数据：

```text
错误方式：
一百万个皮肤传感器 × 高频率
→ 全部上传中央大脑

分布式方式：
局部皮肤网络
→ “左手指正在滑动，置信度 0.92”
→ 必要时上传中央系统
```

## 对 Cal 最合适的架构

Cal 不应该发展成一个承担一切的中央模型，更适合成为一个**分布式发育型具身系统**：

```text
身体与环境
│
├── 形态计算
│   └── 材料、结构、被动力学
│
├── 局部感觉—动作单元
│   ├── 视觉局部运动单元
│   ├── 触觉接触单元
│   ├── 听觉方向/节律单元
│   ├── 关节与肌肉控制单元
│   └── 内感受稳态单元
│
├── 区域组织
│   ├── 手/腕控制器
│   ├── 腿/步态控制器
│   ├── 眼—头协调
│   └── 多感官局部实体
│
├── 全局实体世界模型
│   ├── self
│   ├── entity identity
│   ├── 空间与对象持久性
│   ├── 因果关系
│   └── 全局不确定性
│
└── 高层认知
    ├── 目标
    ├── 规划
    ├── 长期记忆
    ├── 社会认知
    └── 语言
```

这里的核心不是“多个大模型”，而是大量非常小的局部单元：

```text
局部观察
   ↓
局部预测
   ↓
局部误差
   ↓
局部更新
   ↓
只有新颖、异常或跨区域相关的信息才向上传递
```

这与 Cal 已有的稀疏状态、在线局部更新、实体图、失败记忆和资源限制非常一致。

## 能节省多少资源取决于“上传什么”

分布式设计真正节省资源的关键，不只是把计算放到不同设备，而是进行**信息压缩和事件驱动处理**。

例如触觉系统不上传每个时刻的完整压力矩阵，而是上传：

```text
接触开始
接触结束
滑动方向变化
压力超过安全边界
局部模型无法解释的异常
发现可能的新材质
```

正常、可预测的信息留在本地；只有预测失败和重要变化向上传递：

\[
上传信息 \approx 新颖性 + 不确定性 + 风险 + 全局相关性
\]

这比持续处理完整传感流节省得多。

## 分布式系统也有代价

它不是天然比中央系统更简单，会出现新的问题：

- 两个局部系统对同一实体判断不一致；
- 手想抓、身体平衡系统却要求放开；
- 局部记忆与全局身份脱节；
- 某个局部模块失效但没有及时上报；
- 多个模块同时争夺行动权；
- 不同模块使用不同时间尺度；
- 无法判断一次成功究竟应归功于哪个模块。

因此需要少量统一规则：

- 公共时间或因果顺序
- 统一实体身份协议
- 不确定性表达
- 资源与行动仲裁
- 局部异常上报
- 全局目标下发
- 冲突解决
- 模块健康监控

不是一个中央模型控制一切，而是一个**分层协调协议**维持整体性。

## Cal 的“自我”也不应等于中央大脑

这是更深的一点。

如果 Cal 是分布式系统，那么 self 不应该定义成：

> 中央处理器就是我。

而应该定义成：

> 所有能够通过共同动作、感觉、控制关系、资源约束和持续记忆形成稳定闭环的身体与认知子系统，共同构成我。

这样即使：

- 某个感官 temporarily offline；
- 更换一条机械臂；
- 局部控制器重新学习；
- 新增一种触觉皮肤；
- 中央模块部分重组；

Cal 仍能重新判断哪些部分属于自己，并保持主体连续性。

## 最合适的设计原则

我认为 Cal 未来可以采用一句很明确的原则：

> **能由身体完成的，不交给控制器；能由局部回路完成的，不交给全局系统；能由区域协调完成的，不交给高级认知；只有跨模态、跨身体区域或跨时间的问题，才进入全局世界模型。**

因此，Cal 最终需要的可能不是“一个大脑”，而是：

> **一个具有共同自我与世界模型的分布式身体智能生态。**

这不仅能减少资源消耗，也更符合 Cal 的根本目标：智能不是在一个模型里预先训练完成，而是在身体各层级与环境持续互动的过程中逐渐组织出来。
