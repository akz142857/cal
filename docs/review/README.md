# docs/review

本目录存放 Cal 项目的**评审方案**与**评审报告**。

评审的目标不是代码风格，而是保证已发表证据不被污染、保证下一次一次性留出的
消费是值得的。方案与报告的关系：方案是流程文档（允许修订，须递增版本号并注明
依据）；报告是历史产物，默认不可在位修改——**不改变任何判定的笔误**可在授权
后就地更正并留勘误，**触及判定的更正**（级别、判定、去向状态、结论）一律新增
补充文档。规则见 [`REVIEW_PLAN.md`](REVIEW_PLAN.md) §9.1。

### 2026-08-08｜随机化永久性专案冻结前评审 —— `block`

红队攻击 4 成功：一个无信念候选（常速外推 + 125 条目误差表，无转移核、无逐步
后验传播）通过全部 18 个冻结确认门。根因在协议层而非代码层——评分框架
（`_rank` 的场投影 + 场内质量重归一化）代劳了信念滤波最主要的行为特征。
同时确认：随机化世界**确实消灭了** V8 的点质量几何捷径（raw-sensor 探针由
0.875 塌到 0.545，位置先验贴随机线），两份代码扫描**均未发现 P0/P1 代码缺陷**。

阻断项 3 条 P0、5 条 P1；冻结前必须完成的六项修复见报告结论。
