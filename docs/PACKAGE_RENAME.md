# Python 包命名空间迁移

项目的规范 Python 包名已从 `calmodel` 改为 `cal`。源码目录、导入路径、
发行包名和命令前缀均使用 `cal`。

本次修改只涉及命名空间和配套校验逻辑，不改变 M1–M3 的模型与评估算法。

冻结协议和已完成的一次性确认结果仍保留其中原始的 `calmodel/...` 路径，
因为这些路径属于历史证据，不能在实验完成后改写。迁移关系记录在
`experiments/CAL_NAMESPACE_MIGRATION.json`，并由独立 SHA-256 文件保护。
源码锁校验会先验证历史锁值，再验证迁移后 `cal/...` 文件的当前哈希。
