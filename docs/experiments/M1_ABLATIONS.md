# M1 感官与时序消融记录

日期：2026-07-23

## 目的

检验下一感觉预测和下一身体位置表示分别依赖哪些信息。所有模型使用相同场景种子、经验步数、序列长度、优化器和训练轮数，只改变输入模态或时间关系。

身体探针目标为：

```text
表示(观察(t), 动作(t)) → 身体掩码(t+1)
```

该目标比读取当前身体更能检验动作信息是否进入表示。

## 单模型种子结果

| 条件 | 最佳预测损失 | 下一身体 IoU | 未见姿态 IoU |
| --- | ---: | ---: | ---: |
| 完整 GRU | 0.1911 | 0.4676 | 0.4133 |
| 无状态前馈 | 0.1949 | 0.4665 | 0.4107 |
| 无动作 | 0.1964 | 0.4522 | 0.3784 |
| 无触觉 | 0.2433 | 0.3722 | 0.3016 |
| 无本体感觉 | 0.4408 | 0.4132 | 0.3384 |
| 感官时间打乱 | 0.3536 | 0.4601 | 0.4159 |
| 随机动作标签 | 0.1947 | 0.4585 | 0.4120 |

固定位置身体 IoU 为 0.2904，原始本体感觉线性探针 IoU 为 0.3565。

## 观察

### 预测任务

- 删除本体感觉造成最大预测损失；
- 时间打乱也显著损害预测；
- 删除触觉有明显影响；
- 删除动作或随机化动作标签的影响很小；
- GRU 与前馈模型的预测损失非常接近。

### 身体表示

- 完整表示优于固定位置和原始本体感觉；
- 删除触觉造成最大的身体 IoU 下降；
- 删除本体感觉也造成明显下降，但仍优于原始本体感觉探针；
- 删除动作只有小幅下降；
- 随机动作标签和时间打乱几乎没有破坏身体探针；
- GRU 与前馈表示几乎相同。

## 视觉标签泄漏对照

额外建立一个人为容易的环境：

- 身体像素值：1.0；
- 物体像素值：0.35。

直接用视觉强度阈值即可达到当前身体掩码 IoU 1.0。这证明如果身体和物体外观不同，评测会被表面视觉特征完全解决。正式环境必须继续保持二者外观一致。

## 当前解释

这些结果不支持“当前模型已经依靠时序和动作形成强身体模型”的说法。

更符合证据的解释是：

> 当前隐藏表示主要压缩即时视觉、本体感觉和触觉；动作和循环状态只提供了有限的额外信息。

触觉影响较大可能有两种解释：

1. 接触事件确实帮助模型区分身体和外物；
2. 多任务触觉预测改变了隐藏空间，使线性探针更容易训练。

后续需要通过跨种子重复、触觉可靠性变化和外部运动事件区分这两种解释。

## 方法限制

- 目前每个条件只训练了一个模型随机种子；
- 时间打乱发生在固定序列窗口内部，可能包含来自窗口后部的信息；
- 当前动作幅度较小，相邻画面变化有限；
- 固定基座和双关节身体使当前状态可由本体感觉较容易确定；
- 预测损失由三种模态加权组成，不能仅凭总损失定位原因；
- 探针可读性不等于模型在决策中主动使用该信息。

## 下一步

1. 改变动作幅度，增加动作对未来身体的可辨识影响；
2. 加入外部自主运动，使自因和外因可以真正比较；
3. 对完整、无触觉、无本体感觉和随机动作组运行至少 5 个模型种子；
4. 改变肢体长度并测量零样本性能和适应速度；
5. 测试适应新身体后旧身体能力的保持率。
