# M1h 校准直接因果包络预注册

更新时间：2026-07-23

## 假设与唯一变化

M1g 的直接头召回达标但精确率仅 0.1863，表现为系统性过预测。M1h 保持环境、全
动作包络、32 维状态、固定 20 轮 checkpoint、模型和所有身体门槛不变，唯一变化是：

- `ownership_positive_weight: 1.0`，使用标准无加权 BCE；
- 动作效应辅助项仍保持原权重，不参与包络头校准变化。

这是由二元交叉熵的概率校准性质确定的改动，不搜索中间权重。

## 顺序门

先只训练完整 GRU。未见验证场景包络拟合必须同时达到：

1. IoU 至少 `0.45`；
2. 召回至少 `0.60`；
3. 精确率至少 `0.65`。

失败即停止，不训练三个对照。通过后才训练无动作、前馈和无持续，并沿用 M1g 的
普通身体、未见姿态、预测、参数、时序及五种子门槛。不得继续搜索正例权重。

## 第一门结果

固定 20 轮后，未见验证场景的包络 IoU 为 0、召回为 0、精确率为 1：直接头选择
全零解。M1h 因此停止，未运行对照或身体探针。结合 M1g 的过预测，两个预注册权重
端点分别产生全正倾向与全负倾向；后续不得继续搜索中间正例权重。
