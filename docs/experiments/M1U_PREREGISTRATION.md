# M1u 互斥自身槽选择预注册

更新时间：2026-07-23

M1u 与 M1t 完全相同，唯一变化是将三个槽相互独立的 sigmoid 归属概率改为沿槽维
softmax。场景恰有一条受当前动作控制的自身臂，因此每步归属权重和固定为 1；像素
竞争分配与互斥槽选择共同生成包络。该变化不增加参数。

固定 20 轮、数据、无加权 BCE + Dice、硬视觉子集约束和参数预算均不变。未见验证
包络必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。失败即停止当前
竞争槽家族；通过才运行动作删除、槽逐步重置、同预算前馈和 M1g 的其余身体门。

## 第一门结果

包络 IoU 0.1954、召回 0.3243、精确率 0.3295。互斥选择消除了全选，但三个共享
基座且相互重叠的同构臂没有形成稳定整臂槽。当前竞争槽家族停止，不运行对照。
