# V2-M4 去特权化预注册

日期：2026-07-25
协议：`experiments/V2_M4_UNPRIVILEGED_PROTOCOL.json`
（SHA-256 `983fda8684687d4029bfb0826ac946d99aa651efd5b386aaeb2308dbc4c10a19`，
实现前冻结）

## 假设

诊断版 V2-M4 的唯一未通过门是"无特权视觉"：它把模拟器内部生成的可见性掩码
直接交给智能体。本预注册检验：

> 删除该掩码后，智能体仅凭"看到的占据"加确定性几何遮挡推理（视线
> shadow-casting），能否在完全相同的阈值下保持占据融合与对象永久性能力。

若通过，说明特权掩码从来不是必要输入；若失败，失败模式（隐藏召回坍缩、
运动目标概率丢失）会定位几何推理与真实遮挡之间的缺口。

## 环境改动（相对诊断版）

- 遮挡不再是"屏风远侧波段"规则，改为物理一致的离散视线模型：局部窗口内
  某格被隐藏，当且仅当从相机格到该格的 Bresenham 射线存在严格中间的真实
  占据格；
- 传感器只返回 11×11 的**可见占据**patch——被遮挡的占据格与空格在观察上
  不可区分；
- 不再向智能体提供任何可见性通道；真实可见性只在评测端用于事后打分。

## 正式智能体

对感知 patch 做确定性 shadow-casting（V2 数学核心明确允许确定性图像几何
算法）：以窗口中心为相机格，沿射线遇到已观察占据格后，其后方格子标记为
"未知"，不参与 log-odds 更新。其余机制（log-odds 融合、孤立检测的运动
实体跟踪、前沿信息动作选择）与诊断版一致。

结构性约束（作为门直接检验）：`update()` 的签名中**不存在**可见性参数。

## 对照

- `random_action`：主动信息增益门的基线；
- `assume_all_visible`：同一智能体但关闭遮挡推理，把整个 patch 当可见。
  它必须在隐藏占据召回门上失败（≤0.65 视为失败上限），证明几何推理是
  承重机制而非装饰。

## 门（全部与诊断版阈值相同，实现前冻结）

| 门 | 阈值 |
| --- | ---: |
| 占据 IoU | ≥ 0.70 |
| 隐藏占据召回 | ≥ 0.65 |
| 隐藏 Brier | ≤ 0.12 |
| 隐藏期运动目标概率 | ≥ 0.55 |
| 主动确认步数减少 | ≥ 30% |
| assume_all_visible 隐藏召回 | ≤ 0.65（必须失败） |
| update() 无可见性参数 | 结构检查 |
| 资源 | V2 预算不变 |

## 流程与停止规则

开发种子 500–515 可反复运行；全部门通过后才允许消费一次性留出种子
9301–9316。留出失败不得重跑、不得改协议；新机制需要新的预注册。留出
通过才授权面向原对象永久性 M2 的重连设计评审。

## V2 修订（2026-07-25，留出运行前）

协议：`experiments/V2_M4_UNPRIVILEGED_PROTOCOL_V2.json`
（SHA-256 `89ab12f33cec75536fccbd44c3d4e2628340c31a59addbc102376fdde60364e8`）

v1 开发结果（已归档为
`results/V2-M4-unprivileged-development-v1-summary.json`）：八个正式门
全部通过（IoU 0.9202、隐藏召回 0.9320、Brier 0.0065、隐藏期运动目标
概率 0.5925、主动步数减少 75.9%），但 `assume_all_visible` 对照**没有
按预期失败**——其隐藏召回 0.9386、运动目标概率 0.6708，均不低于正式
智能体。

诊断：

1. 隐藏格指标被视野外格子主导，两种变体靠同样的记忆机制维持；
2. 运动目标的短暂遮挡被运动外推桥接，可见性错判造成的擦除来不及显现；
3. 阴影带内没有静态占据，擦除效应缺少持续受害者。

结论：v1 环境无法区分"遮挡推理承重"与"运动外推兜底"。这本身是一个
有效的负结果：在弱遮挡环境里，特权掩码和几何推理都不是必要的。

v2 修订按"先更新世界假设"规则强化环境而不放松任何正式阈值：

- 运动目标每次到达屏风两侧三格处暂停 10 步（外推无法桥接）；
- 阴影带内加入两个带种子抖动的静态障碍；
- 对照判据移到隐藏期运动目标概率（≤0.55 判失败）——把整个 patch 当
  可见时，暂停在阴影里的目标会被持续 -2.2 驱向"自由"，该指标必然坍缩。

留出种子与全部正式阈值不变；修订发生在任何留出运行之前
（`holdout_runs_before_amendment: 0`）。
