# M1q 全局动作查询归属预注册

更新时间：2026-07-23

M1p 表明局部空间状态召回高但无法排除同构外部臂。M1q 使用全局内容查询：

- 当前视觉、有符号变化和绝对变化经 3×3 卷积成为 16 维像素 token；
- token 全局均值与 8 维动作嵌入更新 16 维循环查询；
- 查询与全部 256 个 token 的键做缩放点积，输出归属 logit；
- 使用 M1o 的硬背景约束、无加权 BCE + Dice、固定 20 轮；
- 不启用向量 ownership、部件槽或空间 ConvGRU；
- 总参数仍不得超过 M1b 平衡 GRU 的 1.1 倍。

未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。
失败即停止；通过才训练无动作、查询逐步重置和同预算前馈，并沿用 M1g 的身体、
时序与五种子门槛。

## 第一门结果

包络 IoU 0.3425、召回 0.6502、精确率 0.4198；参数 139,724。召回通过但 IoU和
精确率失败。查询是全局的，但局部 token 不含长程部件上下文。M1q 停止。
