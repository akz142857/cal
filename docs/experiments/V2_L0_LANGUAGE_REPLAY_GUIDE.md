# L0 语言能力交互式回放指南

## 1. 这个页面回答什么

这个页面不是让系统自由聊天，而是回答一个更基础、也更容易严格验证的问题：

> I1 已经形成的“我、其他实体、位置、遮挡和身份历史”，能不能被一个很简单
> 的读出器稳定翻译成语言命题？

页面把同一时间步的四层信息并排放在一起：

1. 世界真值：只给人和离线评分器看。
2. 局部观测：I1 当前真正能看到的占据。
3. I1 信念：I1 根据观测、动作和历史形成的实体状态。
4. L0 语言：独立线性读出器对 10 个受控中文命题给出的真假概率。

因此，你可以直接沿着“世界发生什么 → I1 看到什么 → I1 相信什么 → L0
说出什么”这条链观察系统。

## 2. 生成和打开

生成默认页面：

```bash
uv run cal-v2-l0-language-replay --seed 33100
```

生成文件：

```text
docs/experiments/assets/v2_l0_language_replay_seed33100.html
```

这个 HTML 是单文件，无外部字体、脚本或网络资源，可以直接用浏览器打开。

列出允许重复运行的种子：

```bash
uv run cal-v2-l0-language-replay --list-seeds
```

输出固定为：

```text
33100 33101 33102 33103
```

验证已有 HTML 是否和当前生成器逐字节一致：

```bash
uv run cal-v2-l0-language-replay --seed 33100 \
  --check docs/experiments/assets/v2_l0_language_replay_seed33100.html
```

## 3. 页面怎么使用

- “播放 / 上一步 / 时间轴”：逐帧查看系统变化。
- “语言读出来源”：
  - `I1 实体信念图`：从冻结 I1 的实体状态读取语言。
  - `原始局部传感器（对照）`：只用当前二值占据和动作。
- “跳转到关键事件”：直接跳到自我识别、进入遮挡、重新出现、首次 permanence
  命题或首次 identity 命题。
- “只看当前有效命题”：隐藏本步没有注册评分的查询，便于集中观察。
- 三张画布上的彩色圆环把语言查询指回具体格子：
  - `我1 / 我2`：两个自我候选；
  - `存1 / 存2`：两个被遮挡位置；
  - `同1 / 同2`：两个重现身份候选。
- 每个语言行显示：
  - 中文命题；
  - 命题为真的概率；
  - 模型判断“真”或“假”；
  - 离线真值；
  - 当前判断是否正确。

第 0–11 步是 warmup。I1 正在积累最初的轨迹和自我证据，语言查询从第 12
步开始。

## 4. 最值得看的三个位置

### 自我识别

跳到“识别出自己”附近，观察 I1 的 self 轨迹稳定后：

- “第一处标记指着我”；
- “第二处标记指着我”。

这两个命题是一真一假的成对查询，避免系统仅靠固定回答蒙对。

### 遮挡后仍存在

跳到“首次出现遮挡后仍存在命题”。两个查询分别指向：

- 一个被遮挡但真实仍有实体的位置；
- 一个同样不可见、但实际为空的位置。

如果读出器能区分二者，它读取的不是“现在看见了什么”，而是 I1 对不可见
实体仍然存在的内部信念。

### 重现后身份

跳到“首次出现重现后身份命题”。两个候选在当前帧都可见，但只有一个是遮挡
前保存的那个对象。要答对，系统需要使用遮挡前的历史指称，而不只是当前画面。

## 5. 为什么要切换到“原始局部传感器”

只看正式系统答对，仍不能说明答案来自 I1 的实体结构。原始传感器也可能包含
足够的短路线索。

冻结 V6 development 整体结果中：

- I1 实体信念图四类宏平均平衡准确率：`0.971`；
- 原始局部传感器对照：`0.668`。

切换读出来源后，世界轨迹、动作、语言命题和评分方法都不变，只改变读出器
看到的表示。这让“实体信念图是否增加语言可读性”变成可以直接比较的问题。

## 6. 页面证明了什么、没有证明什么

它支持的结论是：

> 冻结 I1 状态中的自我、空间关系、遮挡后仍存在和重现后身份信息，可以被一个
> 简单线性读出器转成受控中文命题，并且整体上明显优于原始传感器对照。

它没有证明：

- 自然语言习得；
- 自由文本理解或生成；
- 指令跟随；
- 语言控制动作；
- 从原始像素直接理解语言；
- 已通过 V8 one-shot holdout。

页面上的中文句子是固定模板，实验验证的是模板背后的语义真假是否可读，不是
让模型学习汉语语法。

## 7. 证据与 holdout 安全边界

回放生成器固定使用 V6 的可重复 development 协议：

- 训练 seeds：`33000–33007`；
- 页面允许的 development-validation seeds：`33100–33103`；
- V8 holdout seeds：`33600–33603`，演示程序明确拒绝。

拒绝发生在任何世界模拟或数据收集开始之前。演示不会创建 authorization、
consumption 或 evidence tag，也不会改变已经发布的
`calmodel-l0-v8-source-locked` tag。

本交互页位于 source-lock 之后的独立演示分支。未来如果正式运行 V8 holdout，
必须回到锁定 tag 对应的源码和协议，不能把本演示分支当作正式 holdout 来源。

## 8. 自动验证

回放专项测试：

```bash
uv run pytest tests/test_v2_l0_language_replay.py -q
```

测试覆盖：

- seed allowlist 和 holdout 拒绝；
- L0 样本与 I1 frame 的精确 step 对齐；
- 10 个命题的概率、真值、有效 mask 和正确性；
- 正式实体图与 raw-sensor 是两个不同读出；
- standalone HTML、体积限制和 JavaScript 语法；
- byte-deterministic 重新生成检查；
- 仓库中的参考 HTML 与生成器一致。
