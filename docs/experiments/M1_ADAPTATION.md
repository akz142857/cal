# M1 身体变化与有限经验适应

更新时间：2026-07-23

## 问题

固定身体上的预测模型遇到结构、动作幅度或感官可靠性变化时：

1. 零样本预测会退化多少；
2. 多少新身体经验能恢复预测；
3. 适应后是否损害原身体上的预测。

本实验只评测预测损失，不把“损失下降”解释为已经形成了显式身体概念。

## 方法

- 起点：`M1-gru-full-seed000` 的冻结检查点；
- 变化集合：第一段变长、第二段变长、动作幅度增大、肘关节失效、50% 触觉丢失、本体感觉高斯噪声；
- 每种变化分别从同一个原始检查点开始，避免不同变化间相互污染；
- 适应经验预算：0、32、64、128、256 个环境步；
- 每个预算独立微调 10 轮，不沿上一预算继续训练；
- 新身体适应种子为 300–301，测试种子为 350–351；
- 原身体保持测试使用独立种子 600–601；
- 所有评测标签仍未进入模型训练。

运行命令：

```bash
uv run calmodel-adapt \
  results/M1-gru-full-seed000/checkpoint.pt \
  experiments/baseline.yaml \
  --output results/M1-body-adaptation-seed000
```

原始机器可读结果位于
`results/M1-body-adaptation-seed000/adaptation-summary.json`。`results/` 默认不提交
版本库，因此下表是需要长期保留的实验摘要。

## 结果

损失越低越好。“最佳预算”是在预先指定的五个预算中事后选出的描述性统计，
不能当作独立验证集上的调参结论。

| 变化 | 零样本损失 | 最佳预算（步） | 最佳损失 | 相对变化 | 该点原身体损失 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第一段变长 | 0.2725 | 32 | 0.2464 | -9.6% | 0.1664 |
| 第二段变长 | 0.2700 | 32 | 0.2523 | -6.5% | 0.1688 |
| 动作幅度增大 | 0.2445 | 64 | 0.2421 | -1.0% | 0.1657 |
| 肘关节失效 | 0.1641 | 32 | 0.1518 | -7.5% | 0.1647 |
| 50% 触觉丢失 | 0.1740 | 32 | 0.1705 | -2.0% | 0.1663 |
| 本体感觉噪声 | 0.1931 | 32 | 0.1895 | -1.9% | 0.1668 |

各变化在 256 步时的损失依次为 0.2465、0.2528、0.2530、0.1600、
0.1771 和 0.1970。更多经验并未带来单调改善。

原模型在原身体独立测试集上的损失为 0.1862。各变化的最佳适应点在原身体上的
损失均为 0.1657–0.1688，没有观察到灾难性遗忘；但这是单模型种子、短微调和相近
数据分布下的结果，不能证明长期知识保持。

## 解释

1. 肢体长度改变造成最大的零样本退化，并能被 32 步经验部分修复，说明评测管线
   能检测结构变化和有限适应。
2. 肘关节失效的零样本损失反而低于原身体。这是因为失效关节减少了未来状态的
   多样性，任务本身变简单，不能据此声称模型理解了关节失效。
3. 动作幅度与感官可靠性变化只获得 1%–2% 的最佳改善，并在 256 步时退化。
   当前“全参数、固定轮数微调”不是稳定的在线适应机制。
4. 原身体损失在微调后下降而非上升，可能来自对相同生成过程的额外训练，不代表
   已解决持续学习；后续应增加分布更远的旧任务和更长适应序列。
5. 这些结果仅来自一个模型随机种子。跨五个模型种子复现前，不满足 M1 验收标准。

## 结论

M1.7 的环境变化、零样本评测、经验预算曲线和旧身体回测已经实现。首轮结果支持
“模型可以对部分结构变化做有限修复”，但不支持“经验越多适应越好”或“已具备
稳定身体重构能力”。下一步是完成自因/外因因果评测，并跨模型种子复现核心结果。
