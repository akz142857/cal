# M1o 硬视觉支持空间 ConvGRU 预注册

更新时间：2026-07-23

M1o 保持 M1n 不变，加入硬子集约束：可见帧中当前视觉背景的归属 logit 固定为
`-10`，亮像素保留 ConvGRU 原始 logit，不添加正偏置；整帧遮蔽时不约束输出。
该规则直接来自已经逐步验证的包络子集不变量。

未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。
失败即停止；通过才训练三个对照并沿用 M1g 的身体、时序与五种子门槛。

## 第一门结果

包络 IoU 0.3256、召回 0.5061、精确率 0.4772，三项均未达门槛，但已摆脱全正与
全空退化。M1o 停止。后续只允许一次预注册的 8 通道容量检验，失败后停止该局部
ConvGRU 家族。
