# M1t 竞争式运动部件槽预注册

更新时间：2026-07-23

M1t 回到运动概率 1.0 的完整同构干扰环境，并引入显式对象中心表示：

- 三个 16 维槽对应场景中的三条同构臂；
- 当前视觉、有符号变化、绝对变化和二维坐标编码为像素 token；
- 每步两轮竞争式槽注意力将每个像素分配给一个槽，槽由加权视觉证据更新；
- 每个槽用共享 GRU 累积“槽状态 + 当前动作”的归属证据；
- 槽归属概率与竞争分配相乘，得到单一身体包络；
- 可见时用已经验证的“包络是当前视觉子集”硬约束；
- 固定 20 轮，无加权 BCE + Dice，总参数不得超过 M1b 平衡 GRU 的 1.1 倍。

训练只使用视觉、动作和同状态全动作分支得到的因果包络，不使用身体掩码、关节坐标
或干扰臂身份标签。

顺序门：

1. 未见验证包络 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`；
2. 通过后才训练动作删除、槽逐步重置和同预算前馈三个对照；
3. 沿用 M1g 普通身体门、未见身体门、预测门、参数门和时序门；
4. seed 0 全部门通过后才运行五种子和适应。

第一门失败即停止 M1t，不运行对照或身体探针，也不调槽数、槽维度、注意力轮数或
损失权重。

## 第一门结果

包络 IoU 0.2920、召回 1.0000、精确率 0.2920；参数 140,912。输出等同选择全部
可见占据，说明像素竞争没有阻止三个槽同时被独立 sigmoid 判为自身。依预注册停止，
不运行对照或身体探针。
