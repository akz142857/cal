# M1j 视觉支持的直接因果包络预注册

更新时间：2026-07-23

M1j 沿用 M1i 的无加权 BCE、soft-Dice、固定 20 轮和全部数据，唯一变化是利用已被
数据不变量证明的“包络严格为当前视觉子集”：可见帧中给占据像素 `+3`、背景像素
`-3` 的固定支持 logit，学习头只需选择当前占据中的自身部分。整帧遮蔽时支持项为
零，保留循环状态输出能力。该变化不增加参数。

先只训练完整 GRU。未见验证场景包络 IoU 必须 `≥0.45`、召回 `≥0.60`、精确率
`≥0.65`。失败即停止；通过才训练三个对照并沿用 M1g 的身体、时序与五种子门槛。

## 第一门结果

包络 IoU 0.3318、召回 0.6809、精确率 0.3929。视觉支持显著改善 M1i，但只有召回
通过；模型仍在多个可见同构部件间过选。M1j 停止，不运行对照或身体探针。结果要求
后续表示保留动作效应与当前视觉之间的空间对应，而不是继续调整标量损失权重。
