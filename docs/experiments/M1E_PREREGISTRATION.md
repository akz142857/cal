# M1e 持久可控部件槽预注册

更新时间：2026-07-23

## 假设

M1d 在固定图像坐标中累积历史可控像素，产生轨迹涂抹。M1e 改用低维移动部件槽：

> 若每个槽保存一个部件的当前状态，并以共享转移根据动作效应更新，再用共享空间
> 解码器渲染当前位置，则历史证据会随部件运动而更新而非留在旧像素。多个可交换
> 槽的并集应形成当前身体占据图。

## 机制冻结

- 沿用 M1d 的环境、同状态实际动作/NOOP 分支和可控占据伪目标；
- 使用 3 个部件槽，每槽 8 维；
- 三个槽共享同一个 GRUCell 转移和同一个线性空间解码器；
- 每个槽仅以不同的可学习初始状态打破对称；
- 各槽占据概率的并集构成 `part_slot_mask`；
- 槽并集用权重 1.0、正像素权重 8.0 预测无标签可控占据伪目标；
- 身体探针读取 256 维当前 `part_slot_mask`，并以训练集 PCA 投影到 128 维；
- 原始可用感官用同一训练集流程投影到 128 维；
- 训练不读取身体掩码、姿态、坐标、对象身份或外部臂状态。

## 四个 seed 0 条件

1. 完整：主 GRU、动作输入、跨步部件槽；
2. 无动作：删除动作输入和动作相关辅助项，保留槽结构；
3. 前馈：主核心前馈，槽每步从初始状态更新一次；
4. 无槽持续：完整主 GRU和损失不变，但每步把槽重置到相同可学习初始状态。

无槽持续与完整模型参数完全相同。

## seed 0 门槛

1. 完整槽掩码普通身体 IoU 比 128 维原始感官高至少 `+0.05`；
2. 完整比无动作高至少 `+0.04`；
3. 完整比无槽持续高至少 `+0.03`；
4. 完整比前馈高至少 `+0.04`；
5. 未见姿态与普通身体的四项差异方向一致；
6. 12 步动作干预比无动作和无槽持续均高至少 `+0.03`；
7. 验证主预测优于均值基线，参数不超过 M1b 平衡 GRU 的 1.1 倍。

普通身体前五项全部通过才运行时序筛选；全部七项通过才运行模型种子 0–4。失败
后不得改变槽数、槽维数、并集函数、损失权重、PCA 维数或阈值。

## seed 0 筛选结果

| 条件 | 槽掩码身体 IoU | 未见姿态 IoU |
| --- | ---: | ---: |
| 完整 | 0.2025 | 0.1779 |
| 无动作 | 0.2158 | 0.1894 |
| 前馈 | 0.2091 | 0.1861 |
| 无槽持续 | 0.2157 | 0.1924 |

完整模型低于所有三个对照和固定位置基线 0.2904；普通身体与未见姿态的方向都与
假设相反。预测和参数预算通过，但不足以进入时序筛选。M1e 因此停止，不运行五种子。

槽坐标系没有弥补单个实际动作产生的稀疏伪目标。下一候选必须扩大因果干预覆盖，
而不是继续改变槽结构。
