# M1i Dice 直接因果包络预注册

更新时间：2026-07-23

M1g 的正例权重 8.0 过预测，M1h 的权重 1.0 全零。M1i 不搜索中间权重，保持
无加权 BCE，并新增权重 1.0 的 soft-Dice 损失，直接优化预测包络与目标的集合重叠。
其余环境、模型、固定 20 轮策略和数据完全沿用 M1h。

先只训练完整 GRU。未见验证场景必须同时达到包络 IoU `≥0.45`、召回 `≥0.60`、
精确率 `≥0.65`。失败即停止；通过才训练三个对照，并沿用 M1g 的身体、时序和
五种子门槛。不得调整 Dice 权重或平滑常数。

## 第一门结果

包络 IoU 0.1527、召回 0.3047、精确率 0.2345，三项均失败。Dice 避免了全零解，
但 32 维状态仍不能从压缩表示重建准确空间占据。M1i 停止，不运行对照或身体探针。
