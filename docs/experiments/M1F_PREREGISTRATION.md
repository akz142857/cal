# M1f 全动作因果包络预注册

更新时间：2026-07-23

## 假设

M1e 的部件槽由单个实际动作产生的稀疏边缘驱动。M1f 保持槽架构不变，只扩大主动
干预覆盖：

> 从同一状态执行全部五个动作，以 NOOP 为基准对视觉差取并集，再膨胀一格并与分支
> 前当前视觉相交。该包络标记“任一动作可影响的当前占据像素”，应比单动作边缘更
> 完整地覆盖自身，同时严格抵消所有动作无关的外部变化。

## 训练前包络质量门

使用场景种子 400–403、每种子 128 步，只在评估侧将包络与当前身体掩码比较。
训练前必须同时满足：

1. 包络身体 IoU 至少 `0.45`；
2. 身体召回率至少 `0.60`；
3. 精确率至少 `0.65`；
4. 每一步包络非空且严格为当前视觉子集。

任一失败即停止 M1f，不训练模型，不改变动作集合、膨胀核或阈值。

## 模型与对照

质量门通过后，沿用 M1e 的 3×8 维共享部件槽；唯一训练变化是槽并集预测全动作
包络。身体探针目标改为当前身体。四组仍为完整、无动作、前馈和无槽持续，后者与
完整参数相同。

## seed 0 模型门槛

1. 完整槽图普通身体 IoU 比 128 维原始感官高至少 `+0.05`；
2. 完整比无动作高至少 `+0.04`；
3. 完整比无槽持续高至少 `+0.03`；
4. 完整比前馈高至少 `+0.04`；
5. 未见姿态的四项差异方向一致；
6. 12 步动作干预比无动作和无槽持续均高至少 `+0.03`；
7. 验证主预测优于均值基线，参数不超过 M1b 平衡 GRU 的 1.1 倍。

普通身体前五项通过才运行时序；全部通过才运行模型种子 0–4。

## 筛选结果

训练前包络质量门全部通过：IoU 0.6040、召回率 0.7585、精确率 0.7477，所有步骤
非空且无当前视觉子集违规。

| 条件 | 槽图身体 IoU |
| --- | ---: |
| 完整 | 0.2110 |
| 无动作 | 0.2221 |
| 前馈 | 0.2148 |
| 无槽持续 | 0.2170 |

完整模型低于三个对照和固定位置基线。附加诊断显示冻结槽并集对包络的召回率为
0.9211，但精确率只有 0.0659；三个独立 sigmoid 槽的概率并集退化为近乎整图点亮。
因此 M1f 在普通身体门停止，不运行时序或五种子。包络监督本身通过，但当前多槽
并集参数化未能学习它。
