# M1v 完整动作基效应图预注册

更新时间：2026-07-23

诊断表明三条二值同构臂共享基座并会重叠，当前视觉没有稳定的连通部件分解；但在
同一状态执行不同动作时，外部臂的确定性运动在 action-vs-NOOP 差分中严格抵消。
M1v 因此不再先分对象槽，而直接学习完整动作基：

- 每个状态从视觉、有符号变化、绝对变化和实际动作更新 8 通道空间 GRU；
- 同一空间状态同时预测五个动作相对 NOOP 的逐像素效应；
- 五张预测效应图取并、膨胀并与当前视觉相交，形成预测包络；
- 逐动作效应和合成包络均使用无加权 BCE + soft-Dice；
- 标签来自同状态动作分支的感觉差分，不使用身体掩码、姿态或主体身份。

固定 20 轮，回到干扰臂每步运动的完整环境，总参数不得超过 M1b 平衡 GRU 的
1.1 倍。未见验证包络必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率
`≥0.65`。失败即停止；通过才运行删除实际动作、删除空间持续性和同预算前馈控制，
然后沿用 M1g 的身体、时序、多种子及适应门。

## 第一门结果

合成包络 IoU 0、召回 0、精确率 1.0（无正预测约定）。对 1,280 张未见验证动作
效应图的独立审计同样得到 IoU 0、召回 0、真阳性 0、假阳性 0、漏检 3,201。
因此失败发生在逐动作效应预测本身，不是并集或硬支持。依预注册停止，不运行对照。
