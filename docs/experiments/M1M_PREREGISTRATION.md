# M1m 空间 ConvGRU 归属状态预注册

更新时间：2026-07-23

M1k/L 证明从向量解码的动作效应图不可靠。M1m 新增一个 4 通道 16×16 ConvGRU：

- 输入当前视觉、有符号视觉差、绝对视觉差和 4 维广播动作嵌入；
- 3×3 卷积门在原像素网格上跨步维护归属；
- 1×1 头输出包络，保留 M1j 的当前视觉支持；
- 使用无加权 BCE + 权重 1.0 Dice，固定训练 20 轮；
- 不使用向量 ownership、动作效应或部件槽辅助头；
- 新增参数仍须使总量不超过 M1b 平衡 GRU 的 1.1 倍。

先只训练完整 GRU。未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、
精确率 `≥0.65`。失败即停止；通过才训练无动作、逐步重置空间状态和同预算前馈，
并沿用 M1g 的身体、时序与五种子门槛。

## 第一门结果

包络 IoU 0.2877、召回 1.0、精确率 0.2877，表现为选择全部可见占据。参数量
138,172 合格，但固定 `+3` 视觉支持使外部臂也天然为正，空间状态没有学会足够负的
抑制。M1m 停止，不运行对照或身体探针。
