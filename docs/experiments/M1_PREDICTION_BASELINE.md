# M1 多感官预测基线记录

日期：2026-07-23

## 目的

建立第一把可复现的测量尺，验证当前环境和轨迹是否足以训练动作条件的下一感觉预测模型。

本实验不评测身体表示，也不证明模型已经形成自我—环境边界。

## 数据

- 视觉：16×16 单通道占用图；
- 本体感觉：肩、肘角度的正弦和余弦；
- 触觉：两段肢体的二值接触；
- 动作：5 种离散动作；
- 训练场景种子：0–7；
- 验证场景种子：100–101；
- 每个场景：128 步；
- 序列长度：16；
- 训练序列：120；
- 验证序列：30。

身体和物体掩码未进入模型输入或训练损失。

## 模型

### GRU

- 视觉编码器：小型 CNN；
- 本体、触觉编码器：MLP；
- 动作编码器：Embedding；
- 时序核心：单层 GRU；
- 隐藏状态：128；
- 总可训练参数：138,942；
- 输出：下一视觉、本体感觉和触觉。

### 无状态前馈对照

编码器和预测目标相同，每个时间步独立处理，不保留过去状态。

- 总可训练参数：81,342。

## 重要设计修正

第一次实现要求网络从隐藏状态重新生成整幅下一画面，结果为：

| 方法 | 验证总损失 |
| --- | ---: |
| 复制上一观察 | 0.3945 |
| 均值观察 | 1.8967 |
| 初始 GRU | 1.0264 |

初始 GRU 虽然从 1.42 降至 1.03，但明显差于复制基线。原因是绝大多数像素在相邻时间步保持不变，重新生成完整画面浪费了模型容量。

随后将三个预测头改为残差形式：

```text
下一感觉 = 当前感觉的软复制先验 + 学习到的变化
```

该修正没有使用身体标签，只是让模型重点学习动作造成的变化。

## 修正后的结果

| 方法 | 最佳验证总损失 | 最佳轮次 |
| --- | ---: | ---: |
| 复制上一观察 | 0.3945 | — |
| 均值观察 | 1.8967 | — |
| 前馈残差模型 | 0.1949 | 10 |
| GRU 残差模型 | 0.1911 | 11 |

GRU 相对复制基线降低约 51.6%。其最佳验证损失组成：

| 分量 | 损失 |
| --- | ---: |
| 视觉 BCE | 0.1555 |
| 本体感觉 MSE | 0.0042 |
| 触觉 BCE | 0.1258 |

## 当前结论

可以得出的结论：

- 当前数据能够训练出优于复制和均值基线的动作条件预测器；
- 残差预测比重新生成完整感觉更适合当前环境；
- 完整训练、验证、检查点和基线比较链路已经可运行。

不能得出的结论：

- 不能说明模型已经发现身体；
- 不能说明 GRU 的持续状态是必要的；
- 不能说明结果跨随机种子稳定；
- 不能说明模型适应身体结构变化；
- 不能说明当前结构具有低能耗优势。

GRU 与前馈模型仅相差约 0.0038。该差异可能来自参数量、优化噪声或当前任务对记忆需求不足，必须在 M1.5 的身体表示探针和后续跨种子实验中继续检验。
