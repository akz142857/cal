# V2-M1–M3 综合确认协议 v2 修订记录

日期：2026-07-24  
确认集运行次数：0

v1 协议及其失败开发结果保持不可变。v1 的正式 M1、M2、M3 门全部通过，唯一
失败项是删除 M3 因果似然的“MAP 拓扑 F1 ≤ 0.60”。

该消融的后验在全部开发场景中严格为 0.5/0.5，Brier 为 0.5、NLL 为
`ln(2)`，且 72 步内从未收敛；但原评估器仍用字典顺序对平局执行硬 MAP。
八个开发种子中任意平局选择偶然命中六次，产生 0.75 拓扑 F1。这个指标测量的
是实现顺序，不是消融是否获得因果信息。

因此 v2：

- 不修改 M1、M2、M3 模型或阶段算法；
- 保留相同开发集，以便直接复核修订；
- 删除平局 MAP 拓扑门；
- 直接要求消融保持 0.5、Brier ≥ 0.45、NLL ≥ 0.64，且至少 73 步不收敛；
- 放弃尚未运行的 v1 确认种子，换用全新的 17001–17216；
- 把综合评估器本身加入源码哈希锁。

这属于确认前的开发指标修复，不是确认失败后的改门。v1 协议、v1 开发结果和
各自 SHA-256 均写入 v2 协议，不能覆盖。
