# M1l 主预测差分空间效应预注册

更新时间：2026-07-23

M1k 的独立动作效应头为全零。M1l 保持 M1j 的视觉支持、Dice、环境和固定 20 轮，
但空间注意力种子改为 `|sigmoid(预测下一视觉 logits) - 当前视觉|`，再做固定 3×3
最大池化并以强度 2.0 加到归属 logit。主视觉预测头已由密集下一观察损失训练，
不增加参数。

顺序门：

1. 未见验证场景的派生单步效应 IoU `≥0.10`、召回 `≥0.25`、精确率 `≥0.15`；
2. 包络拟合 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。

任一门失败即停止。两门通过才训练三个对照，并沿用 M1g 的身体、时序与五种子门槛。

## 双门结果

派生单步效应 IoU 0.0175、召回 0.5017、精确率 0.0178，第一门失败；包络拟合
IoU 0.2588、召回 0.7103、精确率 0.2893，也未通过。主预测差分过于弥散，M1l
停止，不运行对照或身体探针。
