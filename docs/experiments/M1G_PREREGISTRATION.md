# M1g 直接因果包络占据状态预注册

更新时间：2026-07-23

## 假设与唯一机制变化

M1f 证明全动作包络本身是高质量无标签身体近似，但三个独立 sigmoid 槽的概率并集
退化为整图点亮。M1g 删除槽分解，使用单一 32 维循环占据状态和单一 sigmoid
空间头直接预测相同包络。环境、数据、包络、损失权重和对照保持不变。

所有条件固定训练 20 轮并使用最后一轮 checkpoint，避免主预测早停截断包络学习。
身体探针读取 256 维 sigmoid 占据图，经训练集 PCA 到 128 维，目标为当前身体。

## seed 0 双门

第一门：未见验证场景的直接头必须先证明学会包络：

1. 包络拟合 IoU 至少 `0.45`；
2. 召回至少 `0.60`；
3. 精确率至少 `0.65`。

第一门失败即停止，不解释身体探针。

第一门通过后，普通身体必须同时满足：

1. 完整模型比 128 维原始感官高至少 `+0.05`；
2. 完整比无动作高至少 `+0.04`；
3. 完整比无持续高至少 `+0.03`；
4. 完整比前馈高至少 `+0.04`；
5. 未见姿态四项方向一致；
6. 主预测优于均值基线，参数不超过 M1b 平衡 GRU 的 1.1 倍。

普通身体全部通过才运行 12 步时序；时序比无动作和无持续均高 `+0.03` 后才运行
模型种子 0–4。失败后不得改变正例权重、状态维数、训练轮数、阈值或 PCA 维数。

## seed 0 第一门结果

固定 20 轮后的完整直接头在未见验证场景上得到：包络 IoU 0.1679、召回 0.6294、
精确率 0.1863。只有召回门通过，IoU 和精确率远低于门槛。因此 M1g 在第一门停止，
四组身体探针、时序和五种子均不运行。

单一头消除了 M1f 的多槽并集退化，但正例权重 8.0 仍导致明显过预测。后续候选若
继续使用已验证包络，必须先解决概率校准，不能改变身体门槛补救。
