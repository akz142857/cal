# M1 扩展机制阶段报告：M1c–M1v

更新时间：2026-07-23

## 结论

M1 扩展机制没有通过身体发现门，M2 保持未启动。该结论不是单个模型失败，而是从
M1c 到 M1v 按预注册顺序排除了低维瓶颈、配对一致性、单动作因果效应、固定坐标
归属、无竞争槽、直接包络头、空间 ConvGRU、全局查询、稳定课程、竞争槽和完整动作
基。没有候选获准绕过首门运行事后对照或五种子确认。

目前最强首门结果是 M1p：IoU 0.4093、召回 0.7907、精确率 0.4591，仍未同时达到
0.45/0.60/0.65。项目因此不能宣称形成了稳定身体表示，也不能进入物体永久性 M2。

## 已确认的正结果

- 同状态穷举五个动作得到的无标签因果包络本身质量为 IoU 0.6040、召回 0.7585、
  精确率 0.7477；
- M1b 已确认连续遮蔽状态保持、动作积分和部分因果读出三个独立子能力；
- 训练输入与身体真值保持物理隔离，身体掩码只由冻结评测重放生成；
- 所有筛选保留配置、检查点、摘要、源码哈希、运行时和决策日志。

这些正结果不足以满足普通身体表示、关键删除对照、跨种子和适应的联合要求。

## 失败定位

1. 包络标签足够好，但从历史观察近似该包络的模型存在全空、全可见或同构臂混选
   三种稳定退化；
2. 三条二值臂共享基座和几何并相互重叠，当前帧不存在简单连通部件分解；
3. 局部通道扩展、全局注意力和降低干扰运动都没有解决精确率；
4. 互斥槽消除全选但破坏召回，说明槽没有稳定对应整条臂；
5. 完整五动作监督仍产生全零逐动作效应，排除了“只因单动作目标太稀疏”的简单解释。

## 门控决定

按研究计划的停止条件：

- 不进入 M2；
- 不为失败候选运行未预注册的对照、多种子或适应；
- 不继续搜索正例权重、槽数、槽维度、注意力层数或空间通道；
- 后续若重启，必须先提出改变可观测性或生成模型假设的新预注册，而不是再微调当前
  包络分类家族。

在此意义上，当前研究计划已得到一个可复现的负结果：现有预测学习与所检验的动作
因果扩展不足以在该同构重叠环境中产生通过验收的身体发现。
