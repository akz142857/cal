# M1c 身体表示机制预注册

更新时间：2026-07-23

## 背景与新假设

M1b 已确认因果读出、持续状态和动作积分，但普通 GRU 身体探针相对 128 维联合
原始感官对照的 IoU 增量只有 `+0.0080`，区间跨零。当前预测器把当前视觉、
本体感觉和触觉直接加到输出；模型可以依靠该残差捷径降低下一步预测损失，而不把
身体结构写入内部状态。

M1c-A 的可证伪假设为：

> 若移除当前感官到预测输出的残差捷径，并要求循环核心在短连续感官遮蔽中从内部
> 状态生成干净的下一观察，则无需身体标签，内部表示应获得超出当前原始感官的身体
> 信息。

## M1c-A 唯一机制变化

- `residual_prediction: false`，视觉、本体感觉和触觉预测全部由内部表示生成；
- 保留 M1b 的 25% 外部运动、4 步训练遮蔽和 0.75 动作保持概率；
- 运动摘要可以进入编码器，但禁止 `motion_passthrough` 直连探针表示；
- 沿用完整 GRU、无动作 GRU和同预算前馈三个条件；
- 主模型不接触身体掩码、事件标签、世界坐标或探针梯度。

## 单种子筛选门槛

使用模型种子 0；所有门槛须同时满足才进入五种子确认：

1. 完整 GRU 的普通身体 IoU 相对 128 维联合原始感官探针至少提高 `+0.03`；
2. 完整 GRU 普通身体 IoU 至少高于无动作 GRU `+0.02`；
3. 完整 GRU 普通身体 IoU 至少高于同预算前馈 `+0.02`；
4. 12 步动作干预遮蔽中，完整 GRU 至少高于无动作 GRU `+0.015`；
5. 验证预测损失优于平均观察基线。

任何一项失败都记录为 M1c-A 反证，不通过调整阈值或只选择有利指标进入多种子阶段。

## 五种子确认门槛

若筛选通过，将固定配置并使用模型种子 0–4：

1. GRU 相对联合原始感官、无动作和前馈的普通身体 IoU 配对 95% 区间下界均高于零；
2. 未见姿态 IoU 得到相同方向；
3. 12 步动作干预的 GRU−无动作区间下界高于零；
4. 六种身体/传感变化中至少四种在 256 步后稳定改善，且旧身体损失不恶化；
5. 参数与 MAC 不超过 M1b 平衡 GRU。

M1c-A 未通过时，不进入 M2；后续候选必须提出不同机制和新的预注册文件。

## M1c-A 筛选结果

M1c-A 在模型种子 0 上得到：

| 条件 | 普通身体 IoU | 相对原始感官增量 | 12 步干预 IoU |
| --- | ---: | ---: | ---: |
| GRU | 0.4642 | +0.0404 | 0.2967 |
| 无动作 GRU | 0.4580 | +0.0342 | 0.2726 |
| 前馈 | 0.4375 | +0.0137 | 0.1797 |

GRU 超过原始感官、前馈、时序无动作和平均观察预测基线四项门槛，但普通身体 IoU
只比无动作 GRU 高 `+0.0062`，未达到预注册的 `+0.02`。因此 M1c-A 判定失败，
不运行五种子确认。该结果反对“仅移除残差捷径就足以产生动作依赖身体表示”。
