# M1c-C 跨场景配对可控状态预注册

更新时间：2026-07-23

## 假设

M1c-B 的视觉差分目标没有优于删除对照。单条轨迹内的视觉变化同时包含身体、接触
物体和随机外部运动，仅靠差分仍无法识别哪些变化跨场景稳定地受同一动作控制。

M1c-C 的可证伪假设为：

> 两个独立物体布局若执行完全相同的随机动作日程，会产生相同身体轨迹但不同外部
> 视觉经历；要求小型可控状态在这类配对经历间一致，可在没有身体标签的情况下分离
> 动作控制的身体因素。

## 数据与机制

- 场景种子两两配对，物体布局独立；
- 每对轨迹使用独立于场景随机数的相同动作序列；
- 每个配对窗口正反两个方向都作为主样本，保持原场景经验数；
- 主预测仍针对每个场景自己的下一观察；
- 32 维可控状态使用配对 MSE，一致性权重固定为 1.0；
- 保留 M1c-B 的视觉差分辅助目标，其他配置完全相同；
- 删除对照保留配对数据和全部参数，仅把配对一致性权重设为零。

配对关系只来自共同动作日程，不读取身体状态、物体坐标、掩码或任何语义标签。

## seed 0 筛选门槛

完整 GRU、无动作 GRU、前馈和无配对一致性四组必须同时满足：

1. 完整可控状态相对 32 维联合原始感官 IoU 增量至少 `+0.03`；
2. 完整 IoU 高于无动作至少 `+0.02`；
3. 完整 IoU 高于前馈至少 `+0.02`；
4. 完整 IoU 高于无配对一致性至少 `+0.03`；
5. 12 步动作干预 IoU 高于无动作至少 `+0.015`；
6. 主预测优于平均观察基线，参数不超过 M1b 的 1.1 倍。

六项全部通过才运行五种子。失败后不得调整一致性权重、状态维数、PCA 维数或阈值
挽救本轮结果。

## 筛选结果

| 条件 | 普通身体 IoU | 相对 32 维原始感官增量 | 12 步干预 IoU |
| --- | ---: | ---: | ---: |
| 完整 GRU | 0.4330 | -0.1182 | 0.2648 |
| 无动作 GRU | 0.4250 | -0.1263 | 0.2441 |
| 前馈 | 0.4256 | -0.1257 | 0.1767 |
| 无配对一致性 | 0.4210 | -0.1303 | 0.2717 |

配对一致性相对删除对照只提高普通 IoU `+0.0121`，且时序 IoU 反而更低；完整与
无动作、前馈的普通差异也都低于门槛，表示仍明显低于 0.5513 的原始感官对照。
M1c-C 因此停止，不运行五种子。小幅方向性收益不足以支持跨场景一致性已分离身体
状态的结论。
