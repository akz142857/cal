# M1s 发展式同构干扰运动课程预注册

更新时间：2026-07-23

M1s 使用 M1p 的 8 通道硬支持 ConvGRU、损失和固定 20 轮，唯一训练环境变化是同构
外部臂每步运动概率从 1.0 降为 0.25。该阶段只检验稳定期能否形成身份。

顺序门：

1. 0.25 环境未见验证包络 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`；
2. 通过后训练无动作、无空间持续和前馈对照，沿用 M1g 身体门；
3. seed 0 全部门通过后才运行五种子；
4. 五种子通过后，在不重训下测试运动概率 0.5 和 1.0，并在各自 256 步无标签适应
   后重新测试；1.0 环境适应后必须恢复到其原始 0.25 IoU 的 90% 以上。

起始环境结果不得单独用于进入 M2。

## 第一门结果

0.25 运动概率下，包络 IoU 0.3435、召回 0.7440、精确率 0.3895。仅召回通过，
IoU 和精确率均失败。依预注册不运行消融、五种子或 0.5/1.0 迁移。降低干扰运动
没有恢复 M1p 的包络拟合，课程假设停止。
