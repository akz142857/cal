# M1r 上下文化全局动作查询预注册

更新时间：2026-07-23

M1r 与 M1q 完全相同，唯一变化是在 16 维视觉 token 上加入一层 2 头全局自注意力
和残差，然后由循环动作查询评分。固定 20 轮、硬支持、损失和门槛均不变，参数仍须
低于 1.1 倍预算。这是查询家族唯一一次上下文扩展。

未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。
失败即停止查询家族；通过才运行三个对照和身体门。

## 第一门结果

包络 IoU 0.3488、召回 0.6705、精确率 0.4209；参数 140,812。仅召回通过，且相对
无自注意力 M1q 改善很小。查询家族停止，不增加层数或头数。
