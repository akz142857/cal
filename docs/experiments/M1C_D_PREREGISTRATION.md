# M1c-D 视觉同构外部臂预注册

更新时间：2026-07-23

## 假设

M1c-A 至 C 都没有证明动作依赖的普通身体表示。关键混淆是：当前场景里只有自身
具有双关节臂的几何形状，单帧视觉和本体感觉已足以让线性探针读取身体掩码。

M1c-D 的可证伪假设为：

> 若场景中加入与自身臂共享基座、几何、限位、动作集合和视觉强度，但初始姿态与
> 运动完全独立的外部臂，则形状和位置不再能标识自身；循环预测器必须利用动作与
> 本体感觉的时间同步，才能优于单帧感官、无动作循环和前馈模型。

## 环境与机制冻结

- 加入 2 个外部双关节臂；
- 外部臂与自身臂使用同一 `BodyConfig`，包括基座、长度和全部半径；
- 每条轨迹按场景种子独立初始化外部臂姿态；
- 每一步每个外部臂以概率 1.0 从相同动作集合独立采样动作；
- 外部臂运动使用独立、按步索引的随机数，不消耗智能体动作随机流；
- 外部臂与自身同色，不进入本体感觉或触觉，也不读取身体标签；
- 评估中自身臂仍是 body 掩码，外部臂像素归入 external 掩码；
- 学习机制沿用 M1c-A：无残差 GRU、无动作 GRU、同预算前馈，不再使用
  M1c-B/C 的可控状态、视觉差分或配对损失。

## 环境有效性门

训练模型前，使用固定种子划分和 128 维训练集 PCA 的线性探针检查单帧泄漏。
相同种子、探针超参数和投影下，旧环境的联合原始感官 IoU 为 0.4238，视觉阈值
IoU 为 0.4240。新环境必须同时满足：

1. 联合原始感官 IoU 不高于 `0.38`；
2. 视觉阈值 IoU 不高于 `0.36`；
3. 两者分别至少比旧环境降低 `0.04`。

任一失败即停止 M1c-D，不训练预测器，不通过改变干扰臂数量、姿态分布或阈值补救。

## seed 0 模型筛选门槛

环境门通过后，完整 GRU、无动作 GRU和前馈模型必须同时满足：

1. 完整 GRU 普通身体 IoU 相对 128 维联合原始感官提高至少 `+0.03`；
2. 完整 GRU 普通身体 IoU高于无动作 GRU至少 `+0.02`；
3. 完整 GRU 普通身体 IoU高于同预算前馈至少 `+0.02`；
4. 12 步动作干预 IoU高于无动作 GRU至少 `+0.015`；
5. 验证预测损失优于平均观察基线，参数不超过 M1b 平衡 GRU。

全部通过才运行模型种子 0–4 的确认实验；确认阶段沿用 M1c-A 的配对置信区间、
未见姿态、适应和计算预算标准。

## 环境筛选结果

同构外部臂把视觉阈值 IoU 从 0.4240 降到 0.3018，下降 0.1222，该项通过。
但 128 维联合原始感官 IoU 仅从 0.4238 降到 0.3953，下降 0.0285；它同时失败于
`≤0.38` 的绝对门槛和 `≥0.04` 的下降门槛。

因此 M1c-D 在训练前停止，GRU、无动作和前馈三组均未运行。结果支持“同构视觉
干扰消除了纯像素形状捷径”，但反对“在保留本体感觉时已充分消除单帧身体捷径”。
