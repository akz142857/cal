# M1p 8 通道硬支持空间 ConvGRU 预注册

更新时间：2026-07-23

M1p 与 M1o 完全相同，唯一变化为 `spatial_ownership_channels: 8`。这是当前局部
ConvGRU 家族唯一一次容量扩展；固定 20 轮、损失和所有阈值不变，参数仍须低于
M1b 平衡 GRU 的 1.1 倍。

未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。
失败即停止整个局部 ConvGRU 候选家族；通过才运行三个对照和身体门。

## 第一门结果

8 通道模型得到包络 IoU 0.4093、召回 0.7907、精确率 0.4591；参数量 140,240。
容量扩展改善 IoU 和召回，但精确率仍未达 0.65。依预注册停止局部 ConvGRU 家族，
不运行对照或身体探针，也不继续扩通道。
