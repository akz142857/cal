# V2-M4 去特权化报告

日期：2026-07-25
协议链：`V2_M4_UNPRIVILEGED_PROTOCOL.json`（v1）→ `_V2.json` → `_V3.json`
（每次修订都在任何留出运行之前，`holdout_runs_before_amendment: 0`）

## 决策

**无特权 M4 在一次性冻结留出（种子 9301–9316，仅运行一次）上通过全部
门，授权面向原研究计划对象永久性 M2 的重连设计评审。**

模拟器可见性掩码不再是智能体输入。正式智能体只接收"看得见的占据"
patch 和动作副本；遮挡由其自身对感知 patch 的确定性 shadow-casting 推断
（`update()` 签名中不存在可见性参数，作为结构门直接检验）。

## 一次性留出结果

| 门 | 阈值 | 留出 | 开发 |
| --- | ---: | ---: | ---: |
| 占据 IoU | ≥ 0.70 | 0.7504 | 0.7660 |
| 隐藏占据召回 | ≥ 0.65 | 0.8713 | 0.9012 |
| 隐藏 Brier | ≤ 0.12 | 0.0157 | 0.0174 |
| 隐藏期运动目标概率 | ≥ 0.55 | **0.7492** | 0.7595 |

留出与开发数字接近，没有对开发种子过拟合的迹象。对照与正式智能体的
分离（0.48 对 0.75）表明可见性推理是承重机制：把遮挡格当作可见空格会
持续把暂停中的隐藏目标"擦成自由"。

## 正式机制

1. **几何可见性推断**：以 patch 中心为相机格，对感知占据做 Bresenham
   shadow-casting；被观察占据格遮住的格子不参与 log-odds 更新；
2. **概率运动假设**（`cal/model/motion_hypotheses.py`）：失联目标维护
   (位置 × 方向 × 暂停倒计时) 的离散信念（850 状态，约 3.4k MAC/步）；
3. **在线暂停规律学习**：从可见驻留观察学习暂停地点与时长（质量门：
   时长 4–14 步、单格干净恢复——插桩证明松弛匹配的静态粘连会污染
   转移模型并撕碎后验）；
4. **挂起—重锚定**：目标可见时滤波器随检测重新锚定而非销毁；
5. **可达区间下限**：速度上界保证目标位于永不收缩的区间内，涂抹以
   区间为下限、学习到的集中峰值叠加其上；模型驱动的证据清除只允许
   发生在"当前估计可见"的格子上——擦除只能来自视觉证据。

## 修订史（每一步失败都保留）

- **v1**：正式门全过，但对照没有按预期失败（隐藏召回 0.9386）——
  隐藏指标被视野外格子主导、短暂遮挡被外推桥接。结论：弱遮挡环境里
  掩码和几何推理都不是必要的。环境按"先更新世界假设"规则强化。
- **v2**：对照可靠失败，但正式 0.5461 / 对照 0.5760 挤在 0.55 门两侧
  刀锋上。插桩定位结构原因：可达下限对可见性推理不敏感，唯一区分面
  （窗口内遮挡样本）只占约 15%。
- **v3**：暂停点移到屏风 ±1（对侧相机的最深阴影）、折返墙收窄到
  [6,18]。区分面扩大后正式/对照拉开为 0.76/0.47，全部门通过。
  全程未改任何阈值、种子、对照判据或智能体约束。

## 不能外推的内容

- 环境是 25×25 确定性网格、单运动目标、离散视线遮挡，不是原始像素
  视频；
- 暂停规律是确定性的，在线学习利用了这一可辨识性；随机暂停世界下
  的校准行为未验证；
- 留出授权的是**重连设计评审**，不是直接开始原对象永久性 M2；
- 一次性留出已消费；后续任何机制修改都需要新的预注册和新的留出。
