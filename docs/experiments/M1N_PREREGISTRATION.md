# M1n 无视觉支持空间 ConvGRU 预注册

更新时间：2026-07-23

M1n 与 M1m 完全相同，唯一变化是 `spatial_ownership_vision_support: false`。空间
ConvGRU 必须直接学习背景、外部臂和自身的正负归属，不再给所有可见像素固定正
logit。Dice、无加权 BCE、4 通道状态和固定 20 轮均不变。

未见验证包络拟合必须同时满足 IoU `≥0.45`、召回 `≥0.60`、精确率 `≥0.65`。
失败即停止；通过才训练三个对照并沿用 M1g 身体、时序与五种子门槛。

## 第一门结果

包络 IoU、召回和精确率均为 0，模型选择空解。M1n 停止。结合 M1m 的全可见解，
后续使用“背景硬排除、前景无正偏置”的支持约束，不再调整软支持强度。
