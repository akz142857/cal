# M1c-F 同状态动作干预可控像素预注册

更新时间：2026-07-23

## 假设

M1c-A 至 E 表明，预测、瓶颈、跨场景一致性和传感消融都没有单独产生可靠的动作
依赖身体表示。M1c-F 改用主动干预提供的无语义监督：

> 从完全相同的世界状态分别执行实际动作与 NOOP。两条分支中的外部物体和同构外部
> 臂经历相同的按步随机变化，下一视觉之差因此只包含该动作的因果感官效应。预测
> 这一差异的低秩状态应把“受我动作控制的像素”写入内部表示。

## 数据和机制

- 沿用 E 的 2 个同构外部臂和无本体感觉设置；
- 每个训练状态复制一次模拟器，反事实分支执行 NOOP，事实分支执行原动作；
- 目标为两条下一视觉的逐像素绝对差；
- 目标只由可观测图像和主动干预构成，不包含身体掩码、姿态、坐标或对象身份；
- 使用 16 维低秩动作效应状态和线性像素头；
- 动作效应 BCE 权重 1.0，正像素权重 8.0，运行前固定；
- 完整 GRU、无动作 GRU和同预算前馈均使用相同反事实目标；
- 普通身体探针仍读取 128 维主表示，原始感官对照使用相同的 128 维训练集 PCA，
  不直接把辅助头输出当作身体预测。

## seed 0 门槛

三组模型必须同时满足：

1. 完整 GRU 普通身体 IoU 比 E 的联合原始感官 0.3451 高至少 `+0.05`；
2. 完整 GRU 比无动作 GRU高至少 `+0.03`；
3. 完整 GRU 比前馈高至少 `+0.03`；
4. 12 步动作干预 IoU比无动作 GRU高至少 `+0.02`；
5. 验证主预测损失优于平均观察基线；
6. 参数量不超过 M1b 平衡 GRU 的 1.1 倍。

全部通过才运行模型种子 0–4。任何失败均停止 F，不调整辅助权重、低秩维数、
正例权重或探针投影挽救结果。

## seed 0 筛选结果

| 条件 | 普通身体 IoU | 原始感官 IoU | 未见姿态 IoU |
| --- | ---: | ---: | ---: |
| 完整 GRU | 0.3625 | 0.3451 | 0.3009 |
| 无动作 GRU | 0.3463 | 0.3427 | 0.2961 |
| 前馈 | 0.3278 | 0.3451 | 0.2814 |

完整 GRU 相对原始感官只提高 0.0174，相对无动作只提高 0.0162；两者分别低于
0.05 和 0.03 门槛。相对前馈提高 0.0348、主预测优于均值基线、参数量 143,363
均通过，但不足以改变停止结论。

因此 F 不运行时序筛选和五种子。结果表明同状态动作干预提供了方向正确的小幅增益，
但低秩辅助目标仍没有让普通表示形成足够强的动作依赖身体绑定。
