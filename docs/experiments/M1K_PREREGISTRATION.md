# M1k 空间动作效应注意力预注册

更新时间：2026-07-23

M1j 的视觉支持提高召回但仍在同构臂间过选。M1k 保持 M1j 的环境、损失、固定
20 轮和视觉支持不变，唯一变化是保留预测动作效应的像素坐标：

- 对单步动作效应概率做固定 3×3 最大池化；
- 映射到 `[-1,1]` 后以固定强度 2.0 加到同位置的归属 logit；
- 不新增参数；整帧遮蔽时效应注意力仍由循环预测产生。

先只训练完整 GRU。未见验证场景包络拟合必须同时达到 IoU `≥0.45`、召回
`≥0.60`、精确率 `≥0.65`。失败即停止；通过才训练无动作、前馈和无持续，并沿用
M1g 的身体、时序和五种子门槛。不得改变池化核或注意力强度。

## 第一门结果

包络 IoU 0.3349、召回 0.6613、精确率 0.4042；只有召回通过。冻结效应头的附加
审计显示单步效应 IoU 与召回均为 0，预测为全零图。因此空间路径只带来小幅改善，
但其种子没有学会真实动作效应。M1k 停止，不运行对照或身体探针。
