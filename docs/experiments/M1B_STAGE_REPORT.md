# M1b 动作因果机制回退实验

更新时间：2026-07-23

## 结论

M1b 的候选机制通过了“能否让事件后表示读取外部变化”“遮蔽期间是否需要持续
状态”和“长遮蔽中是否使用动作输入”三项门槛，但还没有证明完整的身体发现能力
已经恢复。运动变化支路把五种子
事件后平衡准确率从原 M1 的
`0.4925±0.0118` 提高到 `0.6283±0.0210`，95% t 区间约为 `[0.6023, 0.6543]`；
事件前状态为 `0.4956±0.0109`，仍接近机会水平。去掉运动支路后为
`0.4996±0.0175`。

在独立确认集的 12 步动作干预遮蔽中，完整 GRU 身体 IoU 为
`0.2891±0.0160`，无动作 GRU 为 `0.2636±0.0128`，前馈为
`0.1683±0.0097`。完整减无动作的五种子配对差异为 `+0.0255`，95% 区间
`[+0.0069,+0.0440]`。因此动作积分证据已确认，但普通可见条件下身体 IoU 没有
稳定优于删除对照，适应也未通过，且运动直连仍是显式变化摘要。当前 M1b 机制停止，
不进入 M2，也不能称为完整、自发涌现的身体因果模型。

## 候选机制

在不使用身体或外部事件标签的情况下，训练数据包含 25% 的外部物体运动。候选模型
包含：

1. 四个视觉变化统计、四个本体感觉差分和两个触觉差分组成的 10 维运动输入；
2. 一个 8 维小型运动编码器；
3. 运动摘要直连到隐藏表示，保证变化量不会被循环核心完全丢弃；
4. 动作交换负样本：正确动作的预测损失应低于错误动作；
5. 无标签逆动力学辅助头，从相邻表示预测实际动作。

动作交换和逆动力学只使用轨迹中的动作字段，不使用事件标签或身体掩码。运动摘要
也只是由连续观察计算，不含语义标签。

## 五种子预测和身体探针

完整 M1b 候选（运动直连 + 对比/逆动力学）与无运动支路对照如下：

| 条件 | 预测损失均值±SD | 身体 IoU 均值±SD | 参数 | MAC/步 |
| --- | ---: | ---: | ---: | ---: |
| M1b 完整 | 0.2194±0.0014 | 0.4380±0.0338 | 146,195 | 232,640 |
| 去掉运动支路 | 0.2206±0.0021 | 0.4219±0.0189 | 140,227 | 229,776 |
| 去掉对比/逆动力学（保留运动直连） | 0.2164±0.0018 | 0.4387±0.0285 | 144,810 | 231,260 |

完整候选相对于原 M1 GRU 的预测损失变差（0.2194 对 0.1908），因为训练分布现在
包含外部物体运动；这不是一个可以隐藏的代价。参数只比原 GRU 多 5.2%，MAC 多
1.8%，仍低于 M1b 的 1.1 倍预算上限。

降低对比/逆动力学权重后的平衡候选（0.05/0.02）在五种子上得到预测损失
0.2164±0.0017、身体 IoU 0.4696±0.0310，因此它是后续比较采用的候选。

完整候选与去掉运动支路的身体 IoU 配对差异均值约 `+0.0161`，95% 区间跨过零；
因此运动支路目前主要改善因果读出，不足以宣称提高身体分割表示。

为排除外部物体运动导致的评测分布差异，另在原始无外部运动测试分布上重做身体
探针。完整、无运动和无辅助均值分别为 0.4553、0.4501 和 0.4713；结论不变，
新增机制没有稳定的身体 IoU 优势。

## 自因/外因探针

五个完整候选的事件后平衡准确率为：

```
0.6119, 0.6416, 0.6000, 0.6465, 0.6416
```

事件前准确率为：

```
0.4842, 0.4891, 0.4970, 0.4950, 0.5129
```

去掉运动支路后的事件后准确率为：

```
0.4772, 0.5040, 0.4861, 0.5188, 0.5119
```

完整候选减去无运动对照的事件后准确率差异均值 `+0.1287`，95% 区间约为
`[+0.1173,+0.1401]`。去掉对比/逆动力学但保留运动直连时，准确率为
`0.6099、0.6168、0.6119、0.6287、0.6119`；相对于完整候选的差异区间跨过零，
说明这些辅助目标尚未带来可确认的额外因果读出。

视觉变化量阈值仍约为 `0.803`，所以 M1b 表示的 0.628 并非达到输入可观测上限，
但也没有超越一个简单的显式变化启发式。

## 反事实动作与迁移检查

在五个模型种子、30 个测试窗口上，将每个记录动作替换为下一个动作词表项：

| 条件 | 错动作减正确动作损失 | 正确动作偏好率 |
| --- | ---: | ---: |
| M1b 完整 | 0.0197±0.0020 | 0.980 |
| 去掉运动支路 | 0.0209±0.0028 | 0.987 |
| 去掉对比/逆动力学 | 0.0154±0.0041 | 1.000 |

完整模型确实偏好记录动作的未来预测，但无运动对照同样偏好，不能把该现象归因于
M1b 新机制。动作交换损失目前改善了训练目标的可解释性，却没有形成独立的行为
判据。

外部移动距离迁移（完整 seed 000）得到事件后准确率：

| 距离 | 事件后状态 | 视觉变化阈值 |
| ---: | ---: | ---: |
| 0.04 | 0.6337 | 0.6891 |
| 0.08 | 0.6119 | 0.8030 |
| 0.16 | 0.6475 | 0.8693 |

运动摘要维度从 8 降到 4 的单种子筛选为事件后 0.6307、身体 IoU 0.4373，与
8 维结果接近；这只是维度筛选，不是五种子确认。

遮蔽训练确认 GRU 的五模型种子适应结果见后文；结论仍是动作幅度和感官可靠性
变化不能稳定适应。

## 持续状态对照

平衡候选的同预算前馈版本在五种子上得到：

| 条件 | 预测损失 | 身体 IoU | 事件后因果准确率 |
| --- | ---: | ---: | ---: |
| GRU | 0.2164±0.0017 | 0.4696±0.0310 | 0.6204±0.0126 |
| 前馈 | 0.2164±0.0047 | 0.4949±0.0252 | 0.6091±0.0266 |

GRU 的因果读出均值略高，但身体 IoU 反而低于前馈，且没有对差异的稳定证据。
运动直连让前馈模型也能读取变化摘要；当前循环状态没有贡献足够的跨时间信息。

### 连续感官遮蔽探针

静态身体探针允许模型在每一步重新看到视觉与本体感觉，不足以检验持续状态。为此
新增一个不参与主模型训练的时序探针：

1. 主模型仍只学习下一感官预测，不接触身体掩码；
2. 训练时以 25% 概率将当前视觉、本体感觉和触觉同时置零，预测目标保持干净；
3. 评测时每 16 步遮蔽第 4–11 步，形成连续 8 步全感官空窗；
4. 每个场景独立随机选择持续 16 步的同向关节动作，相邻动作块不重复；
5. 只在遮蔽步骤冻结表示并训练线性身体掩码探针。

独立随机动作块很重要：早期固定动作循环让当前动作类别泄露轨迹阶段，前馈模型也
能据此猜测姿态。修正后的五模型种子结果为：

| 条件 | 普通可见身体 IoU | 8 步遮蔽身体 IoU |
| --- | ---: | ---: |
| 遮蔽训练 GRU | 0.4615±0.0173 | 0.3680±0.0432 |
| 遮蔽训练无动作 GRU | 0.4700±0.0128 | 0.3239±0.0240 |
| 遮蔽训练前馈 | 0.4716±0.0210 | 0.2387±0.0058 |
| 固定位置基线 | — | 0.2450 |

GRU 减前馈的配对 IoU 差异为 `+0.1294`，95% 区间
`[+0.0711,+0.1876]`。五个 GRU 均高于同一固定位置基线，而前馈均值略低于该
基线。这证明当前循环状态确实保留了跨遮蔽期的身体信息，并排除了单纯参数预算或
当前动作读出的解释。

完整 GRU 减无动作 GRU 的配对差异为 `+0.0441`，95% 区间
`[-0.0227,+0.1109]`。因此不能进一步声称隐藏状态可靠地执行了动作积分；它也可能
主要维持遮蔽前姿态和粗粒度运动历史。时序结果通过“持续状态必要性”门槛，但未
通过“动作输入必要性”门槛。

### 动作干预、长度曲线与独立确认

持续动作从遮蔽前延续到遮蔽后时，无动作 GRU 可以从遮蔽前姿态趋势推断动作方向。
更严格的干预策略在每次遮蔽开始时随机切换关节动作，并在空窗内保持；完整模型能
看到动作，无动作模型不能从之前趋势推断它。训练也改为每个 16 步窗口含一个随机
4 步连续感官空窗，并以 0.75 概率重复上一步动作。训练仍不使用身体标签。

发现集模型种子 0–4 的结果为：

| 遮蔽长度 | GRU | 无动作 GRU | 前馈 | GRU−无动作 95% 区间 |
| ---: | ---: | ---: | ---: | ---: |
| 2 | 0.3298±0.0321 | 0.3298±0.0078 | 0.1718±0.0022 | [-0.0330,+0.0330] |
| 4 | 0.3439±0.0153 | 0.3339±0.0207 | 0.1667±0.0053 | [+0.0020,+0.0181] |
| 8 | 0.3152±0.0117 | 0.2975±0.0224 | 0.1684±0.0063 | [-0.0112,+0.0465] |
| 12 | 0.2872±0.0076 | 0.2589±0.0184 | 0.1773±0.0048 | [+0.0130,+0.0437] |

长度是在看到 8 步结果后继续探索的，不能把发现集的 12 步结果直接当确认性证据。
因此固定 12 步为唯一终点，重新训练独立模型种子 5–9。确认集结果为：

| 条件 | 12 步遮蔽身体 IoU |
| --- | ---: |
| GRU | 0.2891±0.0160 |
| 无动作 GRU | 0.2636±0.0128 |
| 前馈 | 0.1683±0.0097 |
| 固定位置基线 | 0.2415 |

GRU 减无动作的配对差异为 `+0.0255`，95% 区间
`[+0.0069,+0.0440]`；GRU 减前馈为 `+0.1208`，区间
`[+0.1018,+0.1398]`。五个确认 GRU 均同时高于对应无动作模型和固定位置基线。
这支持“持续状态在长感官空窗中使用动作更新身体信息”，而不仅是保持遮蔽前姿态。

限制仍然明确：同一确认模型在普通可见探针上，GRU、无动作和前馈 IoU 分别为
`0.3831±0.0600`、`0.3726±0.0507` 和 `0.4297±0.0358`。动作积分能力没有转化为
一般身体分割表示优势。

### 未见身体动力学迁移

确认模型保持冻结，在两个训练中未见的身体动力学上重复同一个 12 步动作干预。
线性探针在各自新身体上训练，因此测试的是冻结表示是否仍包含可读信息，不是固定
探针的像素几何迁移。

| 身体条件 | GRU | 无动作 GRU | 前馈 | GRU−无动作 95% 区间 |
| --- | ---: | ---: | ---: | ---: |
| 训练身体 | 0.2891±0.0160 | 0.2636±0.0128 | 0.1683±0.0097 | [+0.0069,+0.0440] |
| 第一段 0.22→0.28 | 0.2727±0.0094 | 0.2504±0.0097 | 0.1555±0.0060 | [+0.0073,+0.0372] |
| 动作幅度 0.16→0.24 | 0.2637±0.0079 | 0.2377±0.0082 | 0.1858±0.0059 | [+0.0144,+0.0376] |

两个迁移条件中，完整 GRU 的五个模型种子都高于对应无动作模型；配对区间也均高于
零。动作积分读出因此不局限于训练连杆长度或训练动作幅度。绝对 IoU 随动力学变化
下降，且此实验没有在线更新主模型，所以不能据此声称已解决身体变化后的适应。

### 匹配维度的普通身体探针

同参数预算前馈模型使用 176 维核心，而 GRU 使用 128 维核心；加上运动直连后，
原始探针输入分别为 184 和 136 维。为排除线性探针容量差异，在不读取身体标签的
前提下，只用探针训练种子的冻结表示拟合 PCA，并将所有条件统一到 128 维。独立
模型种子 5–9 的普通可见探针为：

| 条件 | 128 维身体 IoU |
| --- | ---: |
| GRU | 0.4292±0.0237 |
| 无动作 GRU | 0.4024±0.0168 |
| 前馈 | 0.4719±0.0213 |

GRU 减无动作的配对差异为 `+0.0269`，95% 区间
`[-0.0189,+0.0726]`；GRU 减前馈为 `-0.0427`，区间
`[-0.0964,+0.0110]`。前馈在五个配对种子上都高于 GRU，但 t 区间因种子间幅度
波动仍跨零。统一表示维度没有恢复普通身体表示门槛，说明原结果不能仅由探针输入
维数解释。

同样将“当前视觉像素 + 本体感觉 + 触觉 + 动作独热码”做无标签 PCA 到 128 维，
作为联合原始感官线性对照，其 IoU 为 `0.4212±0.0035`。各表示相对该对照的增量为：

| 条件 | 相对联合原始感官 IoU 增量 |
| --- | ---: |
| GRU | +0.0080±0.0226，95% 区间 [-0.0200,+0.0361] |
| 无动作 GRU | -0.0188±0.0184，95% 区间 [-0.0417,+0.0040] |
| 前馈 | +0.0507±0.0215，95% 区间 [+0.0240,+0.0774] |

普通 GRU 的大部分可读身体信息已经存在于当前输入中，没有稳定的表示增量；前馈
表示反而产生了稳定增量。因此不能把普通 GRU 探针分数解释为新的、跨时间形成的
身体表示。

### 五种子在线适应与旧身体保持

对确认 GRU 独立执行 0、32、64、128、256 步无标签预测微调。下表的“改善”定义为
零样本改变身体损失减去 256 步损失，正值为改善：

| 变化 | 最终改善均值±SD | 95% 区间 | 改善种子 |
| --- | ---: | ---: | ---: |
| 第一段变长 | +0.0056±0.0057 | [-0.0015,+0.0127] | 4/5 |
| 第二段变长 | +0.0055±0.0065 | [-0.0026,+0.0135] | 4/5 |
| 动作幅度增大 | -0.0034±0.0039 | [-0.0082,+0.0015] | 1/5 |
| 肘关节失效 | +0.0070±0.0023 | [+0.0042,+0.0098] | 5/5 |
| 触觉丢失 50% | +0.0023±0.0045 | [-0.0032,+0.0078] | 3/5 |
| 本体感觉噪声 | +0.0026±0.0049 | [-0.0034,+0.0087] | 3/5 |

只有肘关节失效稳定改善；动作幅度增大平均反而恶化，因此适应门槛未通过。六个变体
的旧身体损失变化区间都完全低于零，且每个变体都是 5/5 保持或改善。这排除了
“适应失败主要由灾难性遗忘造成”的解释：当前问题是有限经验下对新动力学更新不足。

## 解释与限制

- 外部事件现在出现在训练分布中，表示不再只为原身体预测服务；这是相对原 M1 的
  机制改变。
- 运动直连是明确的测量支路，因而证明的是“变化摘要可被稳定保留”，不是“模型
  自己发现了身体所有权”。后续必须加入动作可控性和错误动作反事实的更严格评测。
- 逆动力学头目前没有显著超过只加运动直连的对照；不能把辅助损失单独归因于成功。
- 身体 IoU 仍低于原 M1，表明因果可读性和身体掩码可读性并非同一个能力。
- 训练只使用一个外部运动概率和一个移动距离；需要在不同外部强度、动作幅度和
  物体布局上测试泛化。

## M1b 决策

停止当前 M1b 机制，不进入 M2。M1b 已确认三个可独立保留的子能力：

1. 外部事件后的自因/外因读出；
2. 连续感官遮蔽中的持续身体状态；
3. 可迁移到未见连杆长度和动作幅度的动作积分。

但普通可见身体表示没有稳定超过删除对照或联合原始感官基线，六变体在线适应也只有
肘关节失效通过。继续对同一机制做未预先定义的小幅调参会构成追逐指标。若项目继续，
应提出新的 M1c 假设和预先定义的验收标准，重点改变表示目标或在线更新机制；在它
通过 M1 的身体表示与适应门槛前，M2 保持未启动。
