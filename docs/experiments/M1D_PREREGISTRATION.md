# M1d 跨时间可控像素归属状态预注册

更新时间：2026-07-23

## 假设

M1c-F 的反事实动作效应带来方向正确但不足的普通表示增益。F 只要求主循环状态辅助
预测单步效应，没有要求模型把稀疏的运动边缘累积成持续的“属于身体”状态。

M1d 的可证伪假设为：

> 同状态实际动作与 NOOP 的下一视觉差给出动作造成的稀疏像素；将该差异膨胀一格并
> 与事实分支的下一视觉相交，可形成无语义的当前可控占据伪目标。专用循环状态若
> 跨时间累积这些目标，应能把局部运动证据整合为持续身体归属，并明显依赖动作与
> 跨步记忆。

## 机制冻结

- 环境、传感和数据划分沿用 M1c-F：2 个同构外部臂、无本体感觉；
- 反事实动作效应仍为同一状态下实际动作与 NOOP 的下一视觉绝对差；
- 归属伪目标固定为效应掩码 3×3 最大池化后与事实下一视觉相交；
- 新增 32 维 `ownership_state`，输入为 16 维动作效应状态；
- 完整模型用独立 GRU 跨步更新归属状态，并线性预测归属伪目标；
- 动作效应和归属 BCE 权重均为 1.0，正像素权重均为 8.0；
- 身体探针只读 32 维 `ownership_state`，原始感官使用训练集 PCA 到同样 32 维；
- 不读取身体掩码、姿态、坐标、对象身份或外部臂状态训练模型。

## 四个 seed 0 条件

1. 完整 GRU：动作输入、主 GRU、跨步归属 GRU；
2. 无动作 GRU：删除动作输入和动作相关辅助项，保留同样归属结构；
3. 同预算前馈：主核心前馈，归属 GRU 每步重置；
4. 无累积：完整主 GRU和全部损失不变，但归属 GRU 每步以零状态独立运行。

无累积条件保留与完整模型完全相同的归属 GRU 参数，仅改变状态传播。

## seed 0 门槛

四组必须同时满足：

1. 完整归属状态普通身体 IoU 比 32 维联合可用原始感官高至少 `+0.05`；
2. 完整模型比无动作高至少 `+0.04`；
3. 完整模型比无累积高至少 `+0.03`；
4. 完整模型比前馈高至少 `+0.04`；
5. 12 步动作干预 IoU比无动作和无累积均高至少 `+0.03`；
6. 验证主预测优于平均观察，参数不超过 M1b 平衡 GRU 的 1.1 倍。

全部通过才运行模型种子 0–4。失败后不得改变池化核、状态维数、损失权重、PCA
维数或阈值挽救本轮。

## seed 0 筛选结果

| 条件 | 归属状态身体 IoU | 32 维原始感官 IoU | 未见姿态 IoU |
| --- | ---: | ---: | ---: |
| 完整 GRU | 0.2012 | 0.4026 | 0.1777 |
| 无动作 GRU | 0.2092 | 0.3988 | 0.1804 |
| 前馈 | 0.2150 | 0.4026 | 0.1899 |
| 无累积 | 0.2165 | 0.4026 | 0.1928 |

完整状态不仅没有超过原始感官，还低于三个对照；相对无累积为 -0.0153。预测损失
和 156,611 参数预算通过，但四个普通身体门槛全部失败。因此不运行时序和五种子。

结果反对在固定图像坐标中直接累积可控像素：历史姿态留下的位置轨迹造成涂抹，
无法表示当前身体。后续机制必须在随运动更新的部件/对象坐标系中保持归属。
