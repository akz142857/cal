# M1 自主变化与外部变化因果探针

更新时间：2026-07-23

## 问题

冻结预测模型的隐藏状态能否区分：

- `0`：只有智能体指令造成的身体和视觉变化；
- `1`：同样存在身体动作，但额外发生了不受动作控制的物体移动。

第二类不是用 `NOOP` 伪造的；两类都包含从相同随机策略采样的身体动作。因此标签
不能靠“是否发出了动作”直接猜出。

## 环境与标签隔离

每一步以 0.5 概率选取一个匿名圆形物体，并沿独立的随机方向移动 0.08 个归一化
世界单位。事件随机数只由场景种子和步号决定，不消费动作采样器的随机状态，所以
保存动作后仍可严格重放。

逐步事件标签由评测时的模拟器重放重新生成：

- 不写入轨迹 JSON；
- 不提供给预测模型；
- 不反向传播到预测模型；
- 仅用于冻结表示上的线性分类器。

训练、验证和测试场景种子分别为 700–707、750–751 和 800–803。每个种子 256
步；每个划分独立下采样为严格类别平衡。测试集最终包含 1,010 个事件。

## 时间对齐

事件 `t → t+1` 同时与两种隐藏状态配对：

- `pre`：看到事件结果之前的状态。由于外部事件随机发生，它应当接近机会水平；
- `post`：模型在下一时刻看到事件结果之后的状态。这才是因果可读性的主要指标。

最后一个事件没有后继隐藏状态，因而对所有方法一致地丢弃。

## 对照

除完整 GRU 外，使用完全相同的因果数据评测：

- 无动作输入模型；
- 感官时间打乱训练模型；
- 无循环状态的前馈模型；
- 原始“前观察 + 后观察 + 动作”的线性分类器；
- 仅动作的线性分类器；
- 视觉变化像素绝对值总量的单阈值启发式。

阈值和线性分类器都只在验证划分上选择。主指标是类别平衡准确率，0.5 为机会水平。

## 结果

| 模型/对照 | 事件后状态 | 事件前状态 |
| --- | ---: | ---: |
| 完整 GRU | 0.4822 | 0.4683 |
| 无动作 GRU | 0.4990 | 0.5000 |
| 时间打乱 GRU | 0.4861 | 0.5069 |
| 完整前馈 | 0.5109 | 0.5149 |

不依赖模型的对照在同一测试集上：

| 输入/方法 | 平衡准确率 |
| --- | ---: |
| 原始前后感官对，线性 | 0.4990 |
| 动作，线性 | 0.5010 |
| 视觉变化绝对值阈值 | 0.8030 |

完整 GRU 的事件后状态 BCE 为 0.6976，事件前状态 BCE 为 0.6970，均未优于
平衡二分类的常数概率基线约 0.693。视觉变化阈值的 F1 为 0.8244。

运行示例：

```bash
uv run cal-cause-probe \
  results/M1-gru-full-seed000/checkpoint.pt \
  experiments/baseline.yaml \
  --output results/M1-cause-full-seed000
```

## 解释

1. 外部事件并非不可观测：简单的视觉变化量启发式达到 0.803。
2. 原始像素对上的单层线性分类器失败，而先做绝对差再阈值成功，说明该任务至少
   需要一种非线性变化运算；它不是固定像素位置的简单泄漏。
3. 完整 GRU 的事件后状态仍处于机会水平，且没有优于无动作、时间打乱或前馈模型。
   当前预测目标没有促使表示保留可线性读取的“外部原因”信号。
4. 事件前状态没有预测随机事件，符合实验设计，说明没有明显的标签或随机数泄漏。
5. 本实验只排除了线性可读性。隐藏状态仍可能以非线性形式包含少量信息；若后续
   使用非线性探针，必须同时限制容量并与原始感官对照，避免探针自己学会任务。

## 结论

M1.5 的自因/外因评测管线已经完成，但结果不支持当前核心假设的因果部分。结合
动作消融和前馈对照，现有模型更像一个利用即时感官线索的短期预测器，而不是已经
形成动作条件因果身体模型的学习器。进入 M2 前，应先进行跨模型种子复现、效率
统计和 M1 阶段回退决策。
