# M1c-E 无本体感觉的动作绑定预注册

更新时间：2026-07-23

## 假设

M1c-D 的视觉阈值基线大幅下降，但联合原始感官仍未通过环境门。固定身体几何与
本体感觉共同提供了单帧姿态捷径；同时，无动作循环模型也能读取本体感觉变化，
削弱动作消融的因果含义。

M1c-E 的可证伪假设为：

> 在多个视觉同构、独立运动的双关节臂中，如果不提供本体感觉，只有发出的动作与
> 随后哪条臂运动同步这一时间关系能稳定标识自身；因此动作条件循环模型应明显优于
> 单帧感官、无动作循环和前馈模型。

## 唯一研究变化

- 沿用 M1c-D 的 2 个同构外部臂、共享基座和每步独立运动；
- 三个条件均设置 `include_proprioception: false`；
- 视觉、触觉、动作日程、数据划分、无残差预测和模型预算沿用 M1c-D/M1c-A；
- 完整 GRU 与前馈接收动作，无动作 GRU 不接收动作；
- 不使用身体掩码、姿态、外部臂状态或探针梯度训练预测器。

这不是对 D 的干扰臂数量、姿态或阈值调参，而是检验“动作能否在缺少直接关节
传感时建立身体绑定”的不同传感假设。

## 训练前单帧门

使用与 D 相同的种子、128 维训练集 PCA 和线性探针。必须同时满足：

1. 联合可用原始感官 IoU 不高于 `0.34`；
2. 相比 M1c-D 的 0.3953 至少下降 `0.04`；
3. 视觉阈值 IoU 位于 `[0.28, 0.33]`，确认场景视觉分布没有意外改变。

失败即停止 E，不训练模型。

## seed 0 模型门槛

训练前门通过后，完整 GRU、无动作 GRU和同预算前馈必须同时满足：

1. 完整 GRU 普通身体 IoU 比原始感官高至少 `+0.05`；
2. 完整 GRU 比无动作 GRU高至少 `+0.03`；
3. 完整 GRU 比前馈高至少 `+0.03`；
4. 12 步动作干预 IoU比无动作 GRU高至少 `+0.02`；
5. 验证预测损失优于平均观察基线，参数不超过 M1b 平衡 GRU。

全部通过才运行模型种子 0–4；五种子阶段要求上述三个普通身体差异和时序差异的
配对 95% 区间下界均高于零，并沿用未见姿态、适应和计算预算检查。

## 训练前筛选结果

关闭本体感觉后，128 维联合可用原始感官 IoU 为 0.3451，相比 D 的 0.3953
下降 0.0502，通过下降幅度门槛；视觉阈值仍为 0.3018，也在预注册区间内。
但原始感官 IoU 比绝对上限 0.34 高 0.0051。

因此 M1c-E 在训练前停止，三种预测器均未运行，阈值未作事后调整。结果说明本体
感觉确实贡献了单帧捷径，但当前视觉、触觉和动作仍可线性读取超过预期的身体信息。
