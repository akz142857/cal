# Cal 研究与开发计划

## 1. 项目使命

Cal 的目标不是训练一个缩小版大语言模型，而是从第一性原理研究：

> 一个从随机权重开始的具身学习器，能否仅依靠多感官输入、行动反馈、持续记忆和有限计算，逐步形成身体、物体、因果、规划、社会互动与语言等认知结构。

项目关注“知识如何产生”，而不只是最终任务分数。每一种新能力都必须能通过实验被验证、被推翻，并能追溯到产生它的学习机制。

## 2. 长期目标

最终希望得到一个具有以下性质的发展型智能体：

- 不依赖预训练语言模型或视觉模型；
- 具体知识不是预先写入，而是从经历中形成；
- 使用视觉、听觉、触觉、本体感觉和内部状态共同学习；
- 通过行动主动选择信息，而不是只被动接收数据；
- 具有工作记忆、情景记忆、稳定知识和技能记忆；
- 能持续学习新能力，同时尽量避免灾难性遗忘；
- 能形成可检验的自我模型、物体模型和因果模型；
- 能从社会互动中学习模仿、共同注意和沟通；
- 后期能够将自然语言绑定到已经形成的具身概念；
- 在计算量、内存访问和活动稀疏度上显著优于密集模型基线。

这是一项长期研究目标，不作为任何单个阶段的成功声明。

## 3. 当前核心假设

### 3.1 总假设

持续内部状态、动作条件预测、多感官同步、稀疏连接、主动探索和多时间尺度记忆，可能比单纯增加静态参数更适合产生低能耗的具身智能。

### 3.2 第一个可证伪假设

> 不提供任何身体标签时，动作条件下的视觉、本体感觉和触觉预测，能够在模型内部形成可读取、可迁移的身体表示。

若完整多感官模型没有显著优于无动作、无触觉或时间打乱模型，则该假设不成立，或当前机制不足以支持该假设。

## 4. 研究边界

### 4.1 第一阶段明确不研究

- 主观意识；
- 人格和情绪模拟；
- 自然语言生成；
- 完整人形身体；
- 真实机器人控制；
- 人类级通用智能；
- 与大模型产品进行能力竞赛。

### 4.2 第一阶段禁止使用

- 预训练语言模型；
- 预训练视觉编码器；
- 物体类别标签；
- 身体分割标签训练主模型；
- 人工编写的任务规划轨迹；
- 由评测状态泄漏出的世界坐标；
- 只展示单次成功而不运行对照实验。

身体掩码、物体掩码和世界真实状态只能用于冻结模型后的评测。

## 5. 研究方法

每一项能力都按照以下闭环推进：

```text
提出可证伪假设
        ↓
建立最小环境
        ↓
实现简单基线
        ↓
设计删除机制的对照组
        ↓
运行多随机种子实验
        ↓
分析成功、失败和替代解释
        ↓
决定继续、修改或停止该方向
```

### 5.1 实验优先原则

1. 先证明现象存在，再扩大模型。
2. 先建立普通模型基线，再测试原创架构。
3. 一次实验尽量只改变一个变量。
4. 训练数据与评测标签严格隔离。
5. 失败结果同样记录，不通过修改指标掩盖。
6. 所有结论至少经过多个随机种子复现。
7. 能力、样本效率和计算效率同时报告。

## 6. 全程统一指标

### 6.1 能力指标

- 下一视觉预测误差；
- 下一本体感觉预测误差；
- 下一触觉预测准确率；
- 身体像素线性探针 IoU/F1；
- 自我动作与外部变化的因果分类准确率；
- 物体位置和身份追踪准确率；
- 延迟任务成功率；
- 环境变化后的恢复速度；
- 新任务学习后旧任务保持率。

### 6.2 学习效率指标

- 达到目标性能所需环境步数；
- 达到目标性能所需训练更新次数；
- 单次经验被重放的次数；
- 新身体或新环境适应所需样本数；
- 不同随机种子的均值、标准差和失败率。

### 6.3 计算与能耗代理指标

- 总参数量；
- 每步实际激活参数量；
- 每步乘加运算量；
- 每步读取和写入的状态大小；
- 峰值内存；
- 单步推理延迟；
- 单步训练延迟；
- CPU/GPU 实测功率与每千步能耗，在条件允许时记录。

参数量不能单独作为效率结论。

## 7. 总体阶段路线

```text
M0 研究基础设施
 ↓
M1 身体发现
 ↓
M2 物体与空间
 ↓
M3 因果与主动探索
 ↓
M4 长期记忆与持续学习
 ↓
M5 社会学习
 ↓
M6 涌现式沟通
 ↓
M7 自然语言绑定
 ↓
M8 低能耗架构与真实机器人迁移
```

后续阶段只有在前一阶段达到验收标准后才进入。若前一假设失败，应先记录失败原因并修改研究假设。

### M1 验收标准

至少同时满足：

1. 完整模型的多感官预测显著优于简单预测基线；
2. 主模型从未接触身体标签；
3. 冻结隐藏状态上的线性探针能在未见姿态中读取身体信息；
4. 完整组稳定优于至少两个关键删除对照组；
5. 时间打乱显著削弱身体表示；
6. 模型能在身体结构改变后通过有限经验重新适应；
7. 结果至少在 5 个随机种子上复现；
8. 记录参数量、运算量、状态读写量和延迟；
9. 形成一份包含失败案例的阶段报告。

### M1 停止或回退条件

出现下列情况时，不直接扩大模型：

- 简单前馈模型与循环模型没有差异；
- 身体探针只在固定位置有效；
- 无动作组与完整组表现相同；
- 模型依赖身体和物体的视觉差异；
- 结果不能跨随机种子复现；
- 增加参数量是唯一能改善结果的方法。

应优先检查环境、指标、数据泄漏和研究假设。

M1b 的最低成功标准：

1. 事件后隐藏状态的自因/外因平衡准确率 95% 区间下界高于 0.55；
2. 事件前状态保持机会水平，排除随机事件泄漏；
3. 完整组身体 IoU 稳定优于无动作和至少一个新增机制消融；
4. GRU 或新的持续状态机制稳定优于同预算前馈组；
5. 不依赖身体/物体外观差异，且不超过计算预算。

M1b 首轮候选已完成五种子实验。事件后因果读出为 0.6283±0.0210，事件前为
0.4956±0.0109，满足前两项；但身体 IoU 在原始无外部运动测试分布上为 0.4553，
与无运动和无辅助对照没有稳定差异，前馈持续状态优势也尚未证明。因此 M1b 的
因果门槛通过、整体验收仍未通过，继续做强度/维度和反事实迁移实验，不进入 M2。
详见 M1B_STAGE_REPORT.md。

后续降权平衡候选的五种子身体 IoU 为 0.4696±0.0310，事件后因果读出为
0.6204±0.0126；同预算前馈身体 IoU 为 0.4949±0.0252，因果读出为
0.6091±0.0266。运动直连的因果信号稳定，但循环状态没有带来身体表示优势，
M1b 继续保持回退状态。

加入 25% 输入遮蔽训练后，在每 16 步含 8 步连续全感官遮蔽、且各场景独立随机
选择持续动作块的评测上，GRU 身体 IoU 为 `0.3680±0.0432`，无动作 GRU 为
`0.3239±0.0240`，前馈为 `0.2387±0.0058`，固定位置基线为 `0.2450`。
GRU 减前馈的五种子配对差异为 `+0.1294`，95% 区间
`[+0.0711,+0.1876]`，因此持续状态门槛在真正需要历史的任务上通过。GRU 减
无动作 GRU 的区间为 `[-0.0227,+0.1109]`，说明持续动作从遮蔽前延续时，无动作
模型也能外推遮蔽前趋势。

随后在遮蔽开始时随机切换动作，并用 2/4/8/12 步长度曲线选择 12 步作为确认终点。
独立模型种子 5–9 上，GRU、无动作 GRU 和前馈 IoU 分别为
`0.2891±0.0160`、`0.2636±0.0128` 和 `0.1683±0.0097`。GRU 减无动作的配对
差异为 `+0.0255`，95% 区间 `[+0.0069,+0.0440]`；动作积分门槛因此通过。
但是同组模型的普通可见身体 IoU 仍由前馈占优，身体适应也未恢复。M1b 仍未同时
通过身体表示删除对照与适应标准，继续保持回退状态，不进入 M2。

冻结确认模型在第一段长度从 0.22 变为 0.28 时，GRU 减无动作的配对差异为
`+0.0223`，95% 区间 `[+0.0073,+0.0372]`；动作幅度从 0.16 变为 0.24 时为
`+0.0260`，区间 `[+0.0144,+0.0376]`。动作积分读出已迁移到两种未见身体
动力学，但绝对 IoU 下降且主模型没有在线适应，不能把迁移读出等同于适应成功。

为排除同预算前馈核心维度更大造成的探针容量混杂，只用冻结训练表示拟合无标签
PCA，并把三组探针输入统一到 128 维。GRU、无动作 GRU 和前馈身体 IoU 分别为
`0.4292±0.0237`、`0.4024±0.0168` 和 `0.4719±0.0213`；GRU 相对无动作和
前馈的配对区间都跨零。表示维度不是普通身体表示门槛失败的充分解释。

确认 GRU 的五种子在线适应中，只有肘关节失效在 256 步后稳定改善；动作幅度增大
平均恶化 `0.0034`，长连杆和感官可靠性变化的改善区间均跨零。六个变体的旧身体
损失都在 5/5 种子上保持或改善，因此适应失败不是灾难性遗忘造成。适应门槛仍未
通过。

联合“当前视觉 + 本体感觉 + 触觉 + 动作”经无标签 PCA 到 128 维后的 IoU 为
`0.4212±0.0035`。GRU 相对该原始感官对照的增量仅为 `+0.0080`，95% 区间
`[-0.0200,+0.0361]`；前馈增量为 `+0.0507`，区间
`[+0.0240,+0.0774]`。普通 GRU 探针没有证明形成了超出当前输入的身体信息。

依据停止条件，**停止当前 M1b 机制，不进入 M2**。保留已确认的因果读出、连续
遮蔽状态保持和动作积分为三个独立子能力，但不将其包装为完整身体发现。若继续该
研究方向，必须先提出新的 M1c 假设与预先定义的身体表示/适应验收标准；M2 任务保持
未启动。

### M1c：超出原始感官的动作依赖身体表示

M1c-A 预注册“移除感官残差预测捷径”。seed 0 的 GRU 身体 IoU 为 0.4642，相对
128 维联合原始感官提高 0.0404，也高于前馈 0.0267；但只比无动作 GRU 高
0.0062，未达到预注册 0.02 门槛。因此 M1c-A 停止，不运行五种子。

M1c-B 预注册 32 维可控状态和动作后视觉差分辅助目标。32 维联合原始感官对照达到
0.5513，完整可控状态只有 0.4406；删除视觉差分损失为 0.4418，且完整只比无动作
高 0.0175。三项门槛失败，因此 M1c-B 也停止，不运行五种子。

M1c-C 使用同动作、不同物体布局的配对经历约束 32 维可控状态。完整模型普通 IoU
为 0.4330，只比删除配对损失高 0.0121，低于 0.03 门槛，且仍显著低于 0.5513 的
原始感官对照。C 停止，不运行五种子。

M1c-D 加入两个与自身共享基座和几何、但独立运动的视觉同构外部臂。视觉阈值 IoU
从 0.4240 降到 0.3018，但联合原始感官只降到 0.3953，没有通过预注册的 0.38
训练前门，因此未训练模型。M1c-E 进一步关闭本体感觉，原始感官降到 0.3451，
仍比 0.34 门槛高 0.0051，也在训练前停止。

M1c-F 从同一世界状态分别执行实际动作和 NOOP，以两条下一视觉之差提供无身体标签
的因果可控像素目标。GRU 普通 IoU 为 0.3625，相对原始感官只提高 0.0174，相对
无动作只提高 0.0162，均低于预注册门槛；只通过前馈差异、预测和参数预算。因此 F
在普通身体筛选后停止，不运行时序或五种子。

A–F 全部遵守运行前阈值，没有通过调低门槛进入确认阶段。当前证据反对仅靠预测、
低维瓶颈、跨场景一致性、同构干扰、传感消融或单步因果效应辅助目标就能形成完整
动作依赖身体表示。M2 继续保持未启动；下一轮必须采用能够跨时间累积可控像素并
显式表示持续身体归属的新架构，而不是继续调整现有辅助损失。

M1d 随后把反事实效应膨胀并与事实视觉相交，以 32 维专用 GRU 在图像坐标中累积
身体归属。完整状态 IoU 只有 0.2012，低于 0.4026 的同维原始感官，也低于无动作、
前馈和逐步重置三个对照。该候选在普通身体门停止。失败定位到坐标系：历史姿态的
可控像素在固定图像平面中形成轨迹涂抹，不能代表当前身体；下一机制必须使用随运动
更新的持久部件槽。

M1e 使用三个共享转移与空间解码器的持久部件槽，但完整槽掩码 IoU 仍只有 0.2025，
且低于无动作、前馈和逐步重置。结果排除了“仅把稀疏单动作效应换成移动槽”；
下一候选必须从同一状态穷举动作，构造覆盖任一动作可影响像素的全动作包络。

M1f 的全动作包络本身达到 0.6040 IoU、0.7585 召回和 0.7477 精确率，证明主动
干预可以在无身体标签时构造高质量身体近似。但三槽 sigmoid 并集退化为近乎整图
点亮，完整身体 IoU 只有 0.2110并低于全部对照。下一候选保留已验证的包络，删除
无竞争多槽并集，改用单一直接可控占据头并先验收包络拟合。

M1g 改用单一直接头并固定训练 20 轮，但包络拟合 IoU 仅 0.1679、精确率 0.1863，
在身体探针前停止。召回 0.6294 已达标，说明失败表现为正例权重 8.0 引起的系统性
过预测。下一候选只检验按像素频率校准的无加权 BCE，仍先通过包络拟合门。

M1h 的无加权 BCE 则收敛到全零解，包络 IoU 与召回均为 0。两个权重端点已排除，
不继续搜索中间权重；下一候选使用对类别比例不敏感、直接优化集合重叠的 soft-Dice。

M1i 加入 Dice 后包络 IoU 仍只有 0.1527。M1j 再加入“包络为当前视觉子集”的固定
支持后，IoU 提升到 0.3318、召回达到 0.6809，但精确率仍只有 0.3929。损失与可见
支持已不足以在三条同构臂中选择自身；下一候选必须保留空间动作效应图，并将其作为
当前视觉上的注意力种子进行传播。

M1k 加入空间效应注意力后包络 IoU 仅增至 0.3349；审计发现独立单步效应头为全零
解。下一候选不再依赖稀疏效应解码器，而从主任务的预测下一视觉与当前视觉之差直接
导出空间效应种子。

M1l 的主预测差分效应 IoU 也只有 0.0175，包络 IoU 降至 0.2588。向量状态和静态
像素头的路线至此停止；下一候选使用在 16×16 网格上维护状态的 ConvGRU，直接读取
逐像素视觉变化与动作嵌入。

M1m 的空间 ConvGRU 参数预算合格，但视觉支持使其选择全部可见占据：召回 1.0、
精确率 0.2877。下一候选保留空间循环与 Dice，只删除固定视觉支持，让状态直接决定
同构部件的正负归属。

M1n 删除软支持后转为全空解。M1m/N 两端说明支持应是硬约束而非正偏置：背景可以
按已验证子集不变量排除，但亮像素必须由空间状态自行分类。

M1o 的硬支持得到较平衡但仍不足的包络拟合：IoU 0.3256、召回 0.5061、精确率
0.4772。下一候选只做一次 4→8 空间通道容量检验；若失败即停止局部 ConvGRU 家族。

M1p 的 8 通道模型将 IoU 提高到 0.4093、召回 0.7907，但精确率仍只有 0.4591。
局部 ConvGRU 家族依预注册停止。下一候选使用循环动作查询对全部视觉 token 做全局
选择，检验长程部件归属而非继续扩大局部通道或卷积感受野。

M1q 的全局查询得到 IoU 0.3425、精确率 0.4198；全局查询仍建立在局部 token 上。
下一候选只增加一层 2 头 token 自注意力，使像素在查询前获得全图部件上下文；失败
后停止当前查询家族。

M1r 加入一层全局自注意力后 IoU 仅 0.3488、召回 0.6705、精确率 0.4209。相对
M1q 改善很小，查询家族依预注册停止。

M1s 将 M1p 放入同构干扰臂仅有 25% 概率运动的稳定起始课程，包络 IoU 仍只有
0.3435、召回 0.7440、精确率 0.3895。课程第一门失败，不运行控制、五种子或
高运动概率迁移。下一候选必须真正把视觉拆成竞争部件槽，再在槽级跨时间累积动作
归属，而不是继续降低环境难度。

M1t 用三个竞争式运动槽分配像素，但独立槽归属再次退化为选择全部可见占据：
IoU 0.2920、召回 1.0000、精确率 0.2920。下一候选只检验互斥自身槽选择，不调整
槽容量、训练轮数或损失。

M1u 的互斥槽选择得到 IoU 0.1954、召回 0.3243、精确率 0.3295。三条共享基座并
相互重叠的二值同构臂没有形成稳定的整臂槽，竞争槽家族停止。下一候选直接预测同一
状态下完整的逐动作因果效应图，再合成身体包络。

M1v 的完整动作基和合成包络均收敛到全零：包络 IoU/召回为 0；1,280 张逐动作
效应图上真阳性为 0、漏检 3,201。该结果排除了“单动作目标过稀疏”这一简单解释。
M1c–M1v 扩展筛选至此停止，正式证据见
[`M1_EXTENDED_STAGE_REPORT.md`](experiments/M1_EXTENDED_STAGE_REPORT.md)。
M2 继续保持未启动。

## 10. M2：物体永久性与空间模型

### 研究问题

在物体暂时不可见时，持续状态是否能保持物体的存在、身份和位置？

### 环境扩展

- [ ] 加入遮挡区域；
- [ ] 加入可移动视野；
- [ ] 加入多个外观相同的物体；

- [ ] 加入自运动引起的视觉变化；
- [ ] 避免直接提供绝对坐标。

### 实验

- [ ] 物体被遮挡后的存在预测；
- [ ] 多个相同物体的身份保持；
- [ ] 视角变化后的空间一致性；

- [ ] 循环状态与无状态模型比较；

### 验收标准

## 12. M4：长期记忆与持续学习

### 研究问题

模型如何快速记住新经历，同时不让新学习覆盖旧能力？

```text

情景记忆：具体事件和经历
语义记忆：跨经历的稳定规律
技能记忆：可重复执行的动作结构
```

### 任务

- [ ] 实现有限容量情景记忆；
- [ ] 实现基于惊奇度或价值的写入；
- [ ] 实现记忆检索；
- [ ] 实现经验重放；
- [ ] 实现类似睡眠的离线巩固阶段；
- [ ] 实现遗忘和记忆容量控制；
- [ ] 测试顺序学习中的灾难性遗忘；
- [ ] 测试旧环境、新环境和再次返回旧环境；
- [ ] 比较固定网络、动态模块和稀疏专家结构。

### 验收标准

- 学习新环境后保留规定比例的旧能力；
- 再次进入旧环境时恢复速度明显快于首次学习；
- 记忆容量固定时仍能保留高价值经历；
- 重放和巩固的贡献可以通过删除实验验证。

## 16. M8：低能耗架构与真实机器人

该方向从 M1 开始持续测量，但只有在基本认知能力成立后才进行真实硬件迁移。

### 架构比较顺序

1. 密集 GRU 基线；
2. 随机稀疏循环网络；
3. 模块化局部循环网络；
4. 稀疏专家或事件路由网络；
5. 果蝇连接组启发拓扑；
6. 局部可塑性与三因子学习规则；
7. 脉冲神经网络；
8. 神经形态或存算一体硬件。

### 公平比较要求

- 相同环境；
- 相同训练和测试轨迹；
- 相同经验预算；
- 同时报告总参数与活动参数；
- 同时报告能力、样本效率和实际延迟；
- 不用更大训练预算掩盖架构效率。

### 真实机器人迁移

- [ ] 先迁移传感器和身体模型，不迁移高层语言；
- [ ] 保留底层安全控制、关节限位和急停；
- [ ] 模型输出抽象动作，不直接输出危险电机命令；
- [ ] 测试仿真到现实差距；
- [ ] 记录真实设备功率和磨损成本；
- [ ] 只在模拟器验证稳定后进入物理实验。

## 20. 决策日志

重大设计变更追加到本节，不覆盖历史。

### D-001：使用简单二维身体作为第一个环境

- 状态：已接受
- 原因：降低物理复杂度，隔离多感官身体发现问题。

## 22. 项目完成的含义

Cal 不以“看起来像人”作为完成标准。

只有当一系列认知能力能够在没有对应人工标签的情况下逐步产生，并且每一步都通过对照实验、跨种子复现和效率测量验证，才能认为项目取得实质进展。

最终结果可能是：

- 找到一种有效的发展型学习架构；
- 发现某些生物启发机制并非必要；
- 证明当前预测学习不足以产生目标能力；
- 提供一套可复现的失败结果和新研究问题。

以上结果都具有研究价值。
