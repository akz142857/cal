# Cal V2 升级研究计划

版本：2.0  
日期：2026-07-24  
状态：V2-A–C、M1、冻结留出 M2 与 M3 已通过；当前停止在 M4 无特权视觉门

执行结果见
[`V2_AUDIT_REPORT.md`](experiments/V2_AUDIT_REPORT.md) 与
[`V2_STAGE_REPORT.md`](experiments/V2_STAGE_REPORT.md)。预注册阈值和失败结果均
保留。独立审查发现的 M2 交叉身份失败已通过概率全局关联修复，并在实现前冻结的
新留出集一次性复审通过；M3 的互斥完整身体图假设也通过一次性冻结留出。
随后 M1–M3 又在不读取旧留出的前提下完成一次性全新数据综合确认。M4 仍使用
模拟器可见性掩码，因此不计为正式通过。

## 1. 升级原因

V1 已完成 M1–M1v。它建立了可靠的实验基础，并证明同状态全动作干预可以产生质量
较高的无标签因果包络；但所有身体表示候选都未通过联合门。继续增加 CNN 通道、
注意力层、槽维度或损失权重的边际价值已经很低。

V2 不覆盖 V1 的负结果，也不把失败候选包装成成功。V1 作为基线永久保留，V2 改变
研究问题：

> 不再训练网络直接预测“哪些像素是身体”，而是让视觉智能体通过行动、预测失败、
> 在线系统辨识和主动消歧，逐步形成“哪些持续实体受我控制”的概率模型。

身体掩码降级为评测投影，不再是主学习目标。

## 2. 从 FSD 借鉴什么

Tesla 的公开材料描述了几个值得借鉴的系统原则：

1. **视觉优先**：Tesla 公开支持资料描述了不依赖雷达、由多摄像头与神经网络处理
   驱动的 Tesla Vision 车型配置；
2. **视频而非单帧**：多相机视频被融合为鸟瞰道路、静态设施和三维物体表示；
3. **自运动帮助消歧**：同一场景在不同时间和视角下被重复观察；
4. **占据和几何优先于类别**：先回答空间是否被占据、如何运动，再回答语义；
5. **在不确定性下规划**：感知不必立即给出唯一解释，行为可以继续收集证据；
6. **失败数据闭环**：复杂和罕见片段从真实运行中回流到训练与回归评测；
7. **端侧效率**：吞吐、延迟、确定性、内存和每瓦性能是系统指标。

公开参考：

- [Tesla AI & Robotics](https://www.tesla.com/AI)
- [Tesla Autopilot and Full Self-Driving Capability](https://www.tesla.com/en_SA/support/autopilot)
- [Tesla vision-based occupancy patent](https://patents.google.com/patent/WO2024054585A1/en)

这些材料只能作为设计原则来源，不代表 Tesla 当前未公开软件的完整结构。

## 3. 明确不照搬什么

Tesla 的公开训练规模不符合 Cal 的目标。V2 不采用：

- 依靠车队规模弥补机制不清；
- 依靠大规模人工或自动标签工厂；
- 依靠数十个密集网络并行堆叠；
- 以 GPU 小时增长换取小幅指标提升；
- 把端侧推理高效等同于整个学习过程低能耗；
- 用安全驾驶产品指标替代认知机制验证。

Cal 借鉴 FSD 的闭环和表示原则，但使用数学结构、稀疏状态和在线局部更新替代
大规模训练。

## 4. V2 的不可妥协约束

### 4.1 感知约束

- 外部世界判断以视觉视频为主，不增加雷达或深度真值输入；
- 允许使用动作副本，因为“我执行了什么”是因果学习的必要变量；
- 本体感觉和触觉只作为后续增强或删除对照，不能成为视觉身体掩码捷径；
- 不使用身体、物体、关节或主体身份标签训练正式智能体；
- 评测真值继续与学习观察物理隔离。

### 4.2 学习约束

- 正式智能体必须在线、按时间顺序学习；
- 每条经验默认只消费一次，重放上限为 4 次；
- 预测失败必须更新内部假设、置信度或下一步动作；
- 不允许失败后调用知道正确身体掩码的兜底模块；
- 不允许每个环境重新从随机权重训练；
- 同一智能体必须经历成功、失败、恢复和环境变化。

### 4.3 资源约束

V2 第一阶段的默认预算：

| 项目 | 上限 |
| --- | ---: |
| 可学习参数 | 100,000 |
| 持续活动状态 | 64 KiB |
| 平均每步 MAC | 5,000,000 |
| 每种子环境步数 | 100,000 |
| 单条经验重放 | 4 次 |
| 第一阶段硬件 | CPU |
| 单候选 CPU 训练墙钟 | 2 小时 |

超过任一预算必须在运行前说明新增机制和预期收益。不能仅因扩大模型而豁免。

## 5. 核心认知定义

### 5.1 身体不再定义为外观类别

V2 的操作性定义：

> 身体是一个跨时间持续存在、其状态变化能够被自身动作稳定预测和控制、内部部件
> 满足一致几何约束，并能在失败后重新辨识的实体关系图。

像素掩码只是该实体图投影回图像后的评测结果。

### 5.2 失败不再只是实验停止条件

对每个时间步，智能体必须保存：

- 动作前的世界假设；
- 对动作后视觉事件的概率预测；
- 实际观察；
- 预测残差及其空间位置；
- 被残差削弱的假设；
- 被增强或新生成的替代假设；
- 下一动作的信息价值。

研究者仍可因预算或证据停止一个机制，但智能体内部不能把失败样本丢弃。

## 6. 数学核心

### 6.1 稀疏视觉实体

视觉前端首先提取少量候选：

- 端点；
- 交叉点；
- 骨架段；
- 运动边界；
- 跨帧可匹配的局部特征。

第一版优先使用确定性图像处理和几何算法。只有当解析前端的可重复性上限明确不足，
才允许加入小型 CNN，并将其作为感官前端对照，而不是认知核心。

### 6.2 在线局部动力学

候选实体 \(i\) 的局部状态记为 \(z_{i,t}\)，动作为 \(u_t\)：

\[
z_{i,t+1}=f_i(z_{i,t})+B_{i,t}u_t+\varepsilon_{i,t}
\]

- \(f_i\)：实体的自主或外因运动；
- \(B_i\)：自身动作对该实体的局部控制映射；
- \(\varepsilon_i\)：预测失败。

第一版使用递推最小二乘或卡尔曼式更新估计 \(B_i\) 和协方差，不通过完整数据集反复
反向传播。

### 6.3 几何关系图

节点之间维护：

- 距离稳定性；
- 相对角度；
- 共同运动；
- 刚性或关节约束；
- 遮挡前后的身份连续性。

身体候选不是单个高相关像素，而是同时满足动作可控性与几何一致性的子图。

### 6.4 概率归属

每个节点维护身体归属概率，而不是立即二值化：

\[
p_{i,t}=P(i\in\text{self}\mid o_{0:t},u_{0:t-1})
\]

观察不足时允许多个世界假设并存。概率必须校准，并用 Brier 分数、对数损失和可靠性
曲线评测。

### 6.5 主动消歧

动作选择兼顾信息和成本：

\[
u_t^*=\arg\max_u
I(u;B,\mathcal{G}\mid h_t)
-\lambda_E C_E(u)
-\lambda_R C_R(u)
\]

- \(I\)：动作对控制矩阵与实体图的信息增益；
- \(C_E\)：能耗或动作代价；
- \(C_R\)：安全或状态边界风险。

随机动作保留为对照，但不再是正式智能体的唯一探索策略。

## 7. 第一阶段：先测可识别性，不先训练新模型

### V2-A：精确历史碰撞审计

目标：判断相同视觉—动作历史是否对应不同身体掩码。

任务：

- [x] 对历史长度 \(K=1,2,4,8,16,32\) 构造视觉帧与动作序列哈希；
- [x] 在不同世界状态和种子间搜索哈希完全相同的历史；
- [x] 对相同历史比较当前身体掩码；
- [x] 记录碰撞数量、掩码 IoU 分布和涉及姿态；
- [x] 分别测量单帧、视频、视频加主动动作后的歧义率；
- [x] 为每个可观察等价类计算经验逐像素多数基线（它不是 IoU/F1 的数学 Bayes 上限）。

若同一可观察历史对应多个真值，系统不得被要求立即输出唯一掩码；后续评测必须允许
概率假设或主动继续观察。

### V2-B：小模型监督信息上限

目的不是提供正式方案，而是区分“信息不存在”和“学习机制失败”。

固定运行以下一次性诊断：

| 诊断器 | 输入 | 参数上限 |
| --- | --- | ---: |
| 单帧线性/小 CNN | 当前视觉 | 50k |
| 视频诊断器 | 最近 16 帧视觉 | 100k |
| 视频动作诊断器 | 最近 16 帧视觉与动作 | 100k |
| 因果证据诊断器 | 全动作效应历史 | 100k |

规则：

- 身体标签只进入这些隔离诊断器；
- 诊断器检查点不能被正式智能体加载；
- 不搜索网络深度、宽度或损失；
- 只报告训练、未见种子和未见姿态差距；
- 诊断结果不计入正式身体发现成绩。

解释：

- 单帧高：存在视觉捷径；
- 单帧低、视频高：需要时间；
- 视频低、视频动作高：需要动作因果；
- 全部低：观察分辨率或任务定义不足；
- 训练高、未见低：场景记忆而非可识别性。

### V2-C：因果证据充分性审计

真实全动作效应图不交给正式智能体，只用于回答：

- 它理论上覆盖多少身体像素；
- 哪些姿态、重叠和关节限位导致遗漏；
- 仅用确定性几何规则能达到的最大 IoU；
- 增加历史长度是否减少遗漏；
- 主动选择动作是否优于固定穷举动作。

该审计不是失败兜底。它只判断因果证据是否足以支持下一阶段。

### V2-A–C 进入门

只有满足以下条件才实现正式 V2 智能体：

1. 已量化可观察等价类及其上限；
2. 视频动作诊断显著高于单帧诊断，或因果证据审计证明主动观察可解除歧义；
3. 正式指标已改为不超过可识别上限；
4. 所有诊断符合资源预算；
5. 没有评测标签进入正式学习路径。

## 8. 第二阶段：最小失败驱动智能体

### V2-M1：可控视觉点

环境从最小问题开始：

- 一个受动作控制的视觉点；
- 1–4 个自主移动的同外观点；
- 允许短时遮挡；
- 不提供绝对坐标或身份；
- 动作有小成本。

正式智能体：

1. 建立视觉轨迹候选；
2. 在线估计每条轨迹的动作控制矩阵；
3. 维护控制置信度；
4. 用预测残差更新模型；
5. 主动选择区分候选的动作；
6. 遮挡后保持概率身份。

关键对照：

- 随机动作；
- 删除动作输入；
- 删除在线失败更新；
- 删除不确定性；
- 删除主动信息增益；
- 时间打乱。

验收：

- 未见种子主体轨迹识别 F1 ≥ 0.90；
- 主动策略达到同等置信度所需步数比随机动作少 ≥ 30%；
- 删除动作或失败更新后 F1 至少下降 0.15；
- 遮挡后身份概率保持校准；
- 全部资源指标通过。

### V2-M2：可控刚性结构

在 V2-M1 通过后，把单点扩展为多个共同运动节点：

- 学习距离稳定性；
- 形成刚性子图；
- 区分受控结构与相似外部结构；
- 测试旋转、平移、部分遮挡和交叉。

关键问题：

> 系统能否从多个局部控制关系形成一个持续实体，而不是独立像素集合？

### V2-M3：关节身体图

加入两段关节结构：

- 用局部雅可比描述动作—视觉运动；
- 学习哪些边是刚性、哪些边允许关节转动；
- 在不同姿态间保持节点身份；
- 从控制和几何关系图投影身体掩码；
- 最后才加入共享基座同构干扰臂。

共享基座干扰不是起始环境，而是通过前述阶段后的压力测试。

冻结 M3 复审进一步要求：

- 每个候选是一张三节点、两边的完整身体图；
- 候选后验互斥且严格归一化；
- 观察等价时保持 0.5/0.5，不猜隐藏标签；
- 对称破缺后仅凭预序列动作效应误差移动后验；
- 删除因果似然的对照必须失败。

一次性留出种子 9201–9216 全部门通过，正式授权 V2-M4。该结果仍只使用解析
稀疏视觉节点；7×7 姿态投影验证图选择，不代表已学会原始像素分割。

### V2-M4：视觉占据与对象持续性

借鉴 FSD 的占据思想，但保持小规模：

- 用二维概率占据格表示“哪里有东西”，不先分类；
- 融合视频、自运动和实体图；
- 预测遮挡区域的占据与运动；
- 主动移动视角重新确认；
- 在此阶段通过后才重新连接原计划 M2。

## 9. 失败样本闭环

建立轻量版“车队失败挖掘”：

1. 每个时间步计算预测 NLL、状态创新和归属熵；
2. 只保存最高误差、最高不确定性和模型分歧片段；
3. 聚类为遮挡、重叠、限位、快速运动、身份交换等失败族；
4. 后续学习优先重访尚未解释的失败族；
5. 每个修复必须在历史失败库和普通轨迹上同时回归；
6. 失败库设固定大小，按信息价值替换，不能无限增长。

系统从失败中学习的证据不是“训练损失下降”，而是：

- 同类失败再次出现时，预测误差下降；
- 所需消歧动作减少；
- 旧能力不退化；
- 置信度更校准。

## 10. 评测体系升级

### 10.1 可识别性

- 精确历史碰撞率；
- 可观察等价类大小；
- Bayes 像素 IoU/F1 上限；
- 增加一帧或一个动作后的歧义减少量。

### 10.2 因果与主体形成

- 动作—实体控制矩阵误差；
- 自身实体归属 F1/AUC；
- 主动动作的信息增益；
- 达到置信度阈值所需环境步数；
- 删除动作和失败更新后的性能差。

### 10.3 不确定性

- Brier 分数；
- 对数损失；
- 可靠性曲线；
- 错误且高置信度的比例；
- 遮挡期间的熵变化。

### 10.4 几何与持续性

- 节点身份交换率；
- 边长度误差；
- 关节约束误差；
- 遮挡后重识别率；
- 身体图投影 IoU，仅作为最终外部评测。

### 10.5 资源

- 每步活动状态；
- 每步 MAC；
- 单次在线更新耗时；
- 每千步能耗；
- 失败库大小；
- 每获得 0.01 能力增益的额外计算成本。

## 11. 开发顺序

第一轮只实施以下内容：

1. `identifiability.py`：历史哈希、碰撞搜索、等价类和 Bayes 上限；
2. `diagnostic_ceiling.py`：四个隔离监督诊断器；
3. `causal_sufficiency.py`：全动作效应覆盖和失败姿态分析；
4. `V2_AUDIT_REPORT.md`：决定是否允许进入正式 V2-M1；
5. 通过审计后才实现在线系统辨识智能体。

禁止在审计完成前创建新的 M1w 神经网络候选。

## 12. 决策规则

- V1 的 D-025 继续有效：原包络分类家族保持关闭；
- V2 是新的研究假设，不是对 V1 门槛的事后修改；
- 监督诊断器不能成为正式方案；
- 失败必须进入在线更新，但研究者仍必须遵守资源和安全停止条件；
- 如果视觉历史在目标环境中不可识别，优先增加主动视角和时间证据，不增加评测泄漏；
- 如果解析数学模型通过，神经网络必须证明相对它的必要增益；
- 如果小 CNN 只作为视觉前端，其参数和贡献必须独立消融；
- 任一阶段不通过时，先更新世界假设，不直接扩大网络。

## 13. V2 成功的含义

V2 第一阶段成功不是得到更高身体掩码 IoU，而是证明：

1. 系统知道自己什么时候不知道；
2. 系统会选择动作减少这种不知道；
3. 预测失败会改变后续模型和行为；
4. 可控局部关系会跨时间组成持续实体；
5. 身体掩码能够从该实体模型投影出来；
6. 这一过程在严格资源预算内完成。

只有这六项同时成立，Cal 才重新进入物体永久性和更高级认知阶段。
