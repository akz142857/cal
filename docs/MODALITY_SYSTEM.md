# Cal 模态体系

## 1. 定义

Cal 的模态体系不是一组平铺的输入通道，而是一条从物理信号、具身闭环、
世界状态到社会符号交流的分层结构：

```text
外感受 / 内感受
        ↓
行动闭环与因果归因
        ↓
具身世界模型
        ↓
社会符号系统
```
语言不被定义为与视觉、听觉并列的原始感官。声音和文字分别通过听觉与
视觉进入系统；语言是建立在已形成的具身概念之上的、后天学习的社会符号
通信模态。

## 2. 第一层：感知模态

### 2.1 外感受（exteroception）

- **视觉**：光、颜色、深度、运动和空间结构；
- **听觉**：声音、方向、节律和时间结构；
- **触觉**：接触、压力、滑动、温度和疼痛等身体表面信号。

### 2.2 身体与内部感受

- **本体感觉（proprioception）**：关节、姿态、速度、张力和身体构型；
- **内感受（interoception）**：能量、损伤、稳态需求等内部状态。

这些通道提供信号，但不预先提供“哪个是自己”“哪个是物体”或“这个词
代表什么”等语义标签。

## 3. 第二层：行动闭环

行动闭环连接：

```text
动作意图 → 动作副本 → 世界变化 → 多模态反馈
```

它不是普通感官，而是 Cal 建立因果归因和自我边界的关键机制。智能体通过
比较动作条件预测与无控制预测，逐步判断哪些变化由自身行动引起，并形成
可控实体、自我边界和身体假设。

## 4. 第三层：具身世界模型

世界模型整合多模态时间经验，形成可持续、可检验的内部状态，包括：

- 自我与环境边界；
- 实体及其身份；
- 空间关系；
- 遮挡与对象持久性；
- 控制关系和因果假设；
- 后续阶段中的动作条件预测、规划与记忆。

这些不是新增的物理感官，而是感知与行动闭环产生的认知结构。

## 5. 第四层：社会符号系统

完整语言是建立在具身世界模型之上的双向社会符号通信模态：

```text
语言输入 → 符号识别 → 具身概念与世界状态
具身概念与世界状态 → 符号表达 → 语言输出
```

它由四种逐步发展的能力组成：

1. **语言读出**：内部状态 → 受控语言命题；
2. **语言理解**：语言 → 内部状态更新、查询或约束；
3. **语言落地**：符号与已形成的具身概念双向绑定；
4. **语言交流**：不同主体之间提问、描述、解释和传递经验。

语言可以帮助消歧、减少探索成本和传递经验，但不能替代底层自我、实体、
因果和世界模型的形成。

## 6. 当前能力边界

Cal 当前的 L0 属于第一项，即 **grounded language readout（具身语义语言
读出）**：冻结 I1 实体状态后，测试 self、空间、身份和对象持久性等受控
命题是否可以由简单读出器读取。语言梯度不进入 I1，语言不参与底层概念的
形成。

因此，当前可以将 Cal 描述为具有初步的：

> 世界状态 → 受控符号表达

但不能据此声称已经具有开放式语言理解、自然语言生成或完整的双向语言
能力。尤其 L0 V8 的唯一留出只通过 24 个冻结门槛中的 21 个，完整 L0
语言可读性主张尚未通过。

## 7. 研究 DNA 与禁止替代

Cal 坚持“先具身概念，后语言绑定”的因果顺序：

```text
无标签多模态经验 + 主动行动
              ↓
自我、实体、身份、持久性与因果结构
              ↓
语言读取、绑定与交流
```

以下路线不能替代这条形成路径：

- 用预训练语言模型提供底层概念；
- 用预训练视觉语义直接定义实体和自我；
- 用大规模标注示范或任务轨迹训练端到端动作策略；
- 以语言流畅度掩盖内部状态缺失；
- 让语言监督或评测真值泄漏进入底层世界模型。

OpenVLA 一类视觉—语言—动作模型可以作为外部研究对象或后续实验基线，
但其大规模示范学习、预训练语义和端到端任务策略范式不属于 Cal 的研究
DNA，也不是 Cal 的演进方向。

## 8. 统一分类

```text
Cal
├── 感知层
│   ├── 外感受：视觉、听觉、触觉
│   └── 身体与内部感受：本体感觉、内感受
├── 行动闭环
│   ├── 动作意图
│   ├── 动作副本
│   └── 行动后果与因果归因
├── 具身世界模型
│   ├── 自我
│   ├── 实体与身份
│   ├── 空间与持久性
│   └── 因果、预测、规划与记忆
└── 社会符号系统
    ├── 语言读出（当前初步能力）
    ├── 语言理解
    ├── 语言落地
    └── 主体间语言交流
```
