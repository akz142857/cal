# Security policy

## Reporting

Do not open a public Issue for credentials, private information, arbitrary
code execution, dependency compromise, or a flaw that could invalidate an
unpublished blind evaluation.

Use GitHub's private vulnerability reporting for this repository. If that
feature is unavailable, contact the repository owner through the private
contact method on their GitHub profile. Include affected versions, impact,
reproduction steps, and any suggested mitigation.

Please allow a reasonable period for investigation before public disclosure.

## Scope

The supported version is the latest release on the default branch. Cal is
research software and is not designed for safety-critical deployment.

Research-integrity failures are also in scope when they expose an unpublished
holdout, bypass a one-shot registry, leak evaluation-only labels into learner
inputs, or make recorded provenance misleading.
